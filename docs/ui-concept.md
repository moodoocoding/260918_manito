# 대표 UI 콘셉트 v1

![우리 반 비밀친구 학생·교사 대표 UI 시안](./design/ui-concept-v1.png)

이 시안은 실제 프런트엔드 구현 전 제품의 대표적인 인상과 정보 우선순위를 확인하기 위한 방향성 이미지다. 화면 구조와 문구는 구현·사용성 검증 과정에서 조정한다.

2026-09-27 개발 계획서 v2.0에 맞춰 아래 적용 기준을 보완했다. 이미지의 가상 날짜·통계·기기 테두리는 디자인 연출이며 개발 요구사항이 아니다.

## 학생 화면

- 첫 화면에 `내가 챙길 친구 보기` 봉투와 `오늘의 미션`을 배치한다. 이름은 기본 가림이며 학생이 눌러 연 경우만 표시한다. 시안은 봉투를 연 상태다.
- 미션 행동은 `했어요`, `바꿀래요`, `오늘은 쉴래요`를 제공한다. `선생님께 도움 요청`, `다시 가리기`, `활동 끝내기`도 쉽게 찾을 수 있게 한다.
- 봉투 마스코트, 둥근 카드, 산호색·하늘색·민트색을 사용해 귀엽고 장난스러운 분위기를 만든다.
- 점수, 순위, 연속 접속 보상과 다른 학생 비교는 표시하지 않는다.
- 공용기기를 고려해 로그아웃과 학생 전환을 쉽게 찾을 수 있게 한다.
- 재진입·탭 복귀 시 이름을 다시 가리고, 5분 유휴 시 로그아웃한다. 로딩·회차 없음·일시정지·종료·저장 결과 확인 중 상태를 별도로 디자인한다.

## 교사 화면

- 첫 화면에서 `도움 요청`, `검토할 쪽지`, `확인이 필요한 활동`을 우선 확인한다.
- 학생 활동 현황은 운영 지원을 위한 표로 제공하되 순위나 평가처럼 보이지 않게 한다.
- 회차 일정과 관리 버튼을 같은 화면에 배치한다.
- 전체 매칭 관계와 쪽지 원문은 첫 화면에 노출하지 않는다.
- 학생 화면과 같은 디자인 언어를 사용하되 표·검색·복구 작업의 가독성을 우선한다.
- 미션 미완료 전체를 경고 숫자로 표시하지 않는다. '확인이 필요한 활동'의 집계 기준을 정의하고 도움·접속 오류 등 운영상 필요한 내용만 표현한다.

## 디자인 방향

- 따뜻한 크림색 바탕과 산호색을 중심으로 하늘색, 민트, 라벤더를 보조색으로 사용한다.
- 큰 글자, 큰 버튼, 한 화면 한 과업과 충분한 여백을 유지한다.
- 색상만으로 상태를 구분하지 않고 아이콘과 문구를 함께 사용한다.
- 학생용은 친근한 그림과 짧은 문장, 교사용은 정돈된 카드와 표 중심으로 구성한다.
- 장식은 교실의 쪽지, 연필, 별, 새싹에서 가져오되 정보 읽기를 방해하지 않게 제한한다.

## 구현 시 확인할 사항

- 저·중·고학년별 글자 크기와 문장 난이도
- 키보드 탐색, 초점 표시, 명도 대비와 색각 접근성
- 작은 학교 태블릿과 교사용 PC의 반응형 배치
- 긴 학생 표시 이름과 긴 미션 문장의 줄바꿈
- 로그아웃·화면 가리기·뒤로가기에서 이전 학생 정보 제거
- 도움 요청이 학생에게 낙인이나 불이익처럼 보이지 않는지 확인
- 시안 이미지를 배경으로 붙이지 않고 실제 텍스트·버튼·폼·표로 구현
- [개발 계획서 v2.0](./manitto-development-plan.md)의 D1~D6 단계별 화면·서버 연결 기준과 대조
