- 수행: Codex 한 에이전트가 저장소의 가상 WD-01/02, UX-01/02, UI-01/02 프로파일을 각각 적용했다. 외부 전문가 자문이나 실제 교사·학생 관찰은 아니다.

## 과업·현재 문제·설계안

- 교사는 학급에서 시즌 기간·참가자·미션·쪽지를 정하고, 저장 전에 한눈에 확인한다. 카드 화면에 들어오면 담당 교사가 개인 코드를 명단에서 바로 확인한다.
- 학생은 배정된 친구에게 쪽지를 보내고 받은 쪽지에만 답장한다. 상대를 임의 지정하거나 익명 발신자를 알아내지 못한다. 교사는 전달된 쪽지의 메타데이터를 보고 원문을 개별 열람·감사하며 문제가 있으면 숨긴다.
- 관찰: 기본 정보에 날짜 편집기가 과밀하고, 미션과 쪽지가 한 단계에 혼재한다. 확인 화면의 정의 목록에 2열 규칙이 없어 캡처처럼 값이 들여쓰고 수업일 문자열이 길게 흐른다. 기존 자유 쪽지는 승인 전송이며 답장이 없다. 카드 코드는 인쇄 경로에만 있다.
- 시즌 준비는 **1 기본 정보 → 2 참가자·제외 → 3 미션 → 4 쪽지 → 5 확인·저장**. 기본 정보는 주제, 시작·종료일과 기간 단축만 보여준다. 수업일은 기간의 평일을 자동 산출해 확인 단계에 개수만 표시한다. 학교 휴일 편집은 이번 기본 흐름에서 없애고, 저장 후 상세 운영에서만 필요 시 조정하는 방안을 후속 검토한다.
- 미션은 인사·칭찬, 경청·대화, 협력·배려, 감사·응원 4개 그룹에 각 학년군 10개씩. 한 시즌에는 3개 선택, 교사는 학급 전용 미션을 최대 40개 추가해 선택할 수 있다. 안전하지 않은 미션을 피할 짧은 기준을 입력 옆에 둔다.
- 쪽지는 1:1의 **배정 방향 최초 전송 + 받은 쪽지의 익명 답장**. 자유 입력과 검토된 문구가 즉시 전달되며 교사의 개별 사전 승인은 요구하지 않는다. 남용 방지를 위해 수업일마다 학생당 최대 10건, 200자 제한, 신고·숨김·교사 중단을 유지한다. 운영 화면은 최근 기록을 페이지 단위로 확인하고 원문은 클릭 시 감사 기록을 남기며 열린 원문은 화면 이탈·비활성화 시 가린다. 과거 대기 쪽지 승인 기능은 이미 접수된 기록을 위한 호환 기능으로 둔다.
- 카드 코드는 `학생·입장 카드` 진입 때 담당 교사 전용 Callable로 40명 이하를 읽어 이름 아래 표시하고, 페이지 이탈·탭 비활성·5분 경과 시 가린다. 다시 보기 버튼과 구 카드 재발급 안내를 둔다. 코드가 없는 기존 카드의 재발급은 교사가 확인해야 하며 자동으로 바꾸지 않는다.
- 반응형: 1280px에서 미션 선택 목록 최대 2열, 카드 목록 2열, 800px 이하 모두 1열. 요약 정의 목록은 140px/잔여폭 2열, 600px 이하 1열. 긴 이름·수업일 문자열은 줄바꿈한다. 선택 행 전체·버튼은 44px 이상, 키보드 기본 체크박스/버튼을 유지한다.
- 상태: 빈 카탈로그/오류 재시도, 선택 3개 상한, 추가 미션 저장 중/성공/실패, 쪽지 전송 후 목록 갱신, 답장 가능 여부, 교사의 숨김 확인, 코드 로딩/없음/자동 가림/재조회, 단계별 저장 전 경고.
