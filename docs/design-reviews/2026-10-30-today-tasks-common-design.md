# 전문가 검토 기록: 오늘 할 일 공통 디자인 전환

## 검토 정보

- 날짜: 2026-10-30. 사용자가 지정한 ‘오늘 할 일’ 시안을 공통 기준으로 고정한 이후 전환.
- 수행: Codex 한 에이전트가 6개 가상 프로파일을 개별 적용. 외부 전문가·학생 검증 없음.
- 자료: `AGENTS.md`, `docs/world-design-system.md`, `docs/design-references/world-interior-approved.png`, `WorldPage.tsx`, `world-design-system.css`, 기존 오늘 할 일 구현/검토.
- 소유 범위: 오늘 할 일 컴포넌트·기능 CSS와 관련 기록. main/공통 코드/preview 통합은 부모 채팅 담당.

## 설계와 주요 상태

독립 tt-frame/header/paper/button/theme를 제거하고 실제 WorldPageFrame/WorldPageHeader/WorldPaper/WorldButton/WorldPixelIcon을 사용한다. 미션 목록·상태/입력·오류·저장·빈 상태·기억 정리와 마을/종료 callback을 유지한다. 입력은 공통 world-field를 사용하고, 기능 CSS에는 미션 상태와 카드 배치·연결 상태·목록 분류만 둔다. 공통 header에 별도 도움 prop이 없으므로 도움은 종이의 첫 문맥 줄에 둔다. 새로고침 버튼의 ref 대신 고정 id로 동일한 초점 복귀를 유지한다.

최대1200px 공통 프레임과 최대2열, 768px 이하1열, 320/360/390px 및 긴 제목/설명에서 줄바꿈을 확인한다. 배경·목재 질감·아이콘은 공통 변수의 단일 원본을 사용한다. API와 Schooldoc 제출 값은 이번 시각 변경에서 다루지 않는다. 뒤이어 사용자가 요청한 자동 연결은 별도 검토를 따른다.

## 사용자 교정에 따른 시안 일치 설계 보완

사용자는 같은 시안 이미지를 다시 제시하며 실제 화면과 차이가 크다고 지적했다. 작은 공통 clipboard만 반복한 것, 작은 제목/버튼, 완료 항목의 세로 메타데이터 나열은 시안의 큰 책상·책 삽화/강한 타이포/간결한 완료 행과 다르다.

- 공통 bitmap에서 미션 제목이 명확하게 독서/정리/편지/게시/배려 계열을 뜻할 때 해당 삽화를 고른다. 여러 계열이 겹치거나 모르면 clipboard를 쓴다. 표시만 바꾸며 API/body/미션 원문은 그대로다.
- 진행 미션은 큰 삽화와 제목/안내를 한 묶음으로 배치하고 날짜·큰 공통 CTA를 아래에 둔다. 완료 미션은 제목/배지/저장 설명의 가로 요약이며 내용·기간·취소·최종 변경은 명시적 details에서 모두 제공한다. 취소 기능을 삭제하지 않는다.
- 공통 제목/본문/버튼·양피지 재질 변경은 부모 소유 공통 원본에서 반영하도록 요청했다. 동일1536×1024 기준 비교와 320~768px 재배치를 각각 확인한다.

| 관점 | 보완 설계 개별 판단 | 판정 |
|---|---|---|
| WD-01 | 삽화 점유와 과업 초점을 키우고 완료 행을 간결하게 한다. 공통 재질/버튼을 독립 복제하지 않는다. | 통과 |
| WD-02 | 큰 삽화는 1280 이상에서 최대2열 안에, 좁은 폭에서는 한 열과 축소된 삽화로 줄바꿈한다. | 통과 |
| UX-01 | 완료 관리 진입에 ‘내용·취소’를 명시해 취소 위치를 예측하게 하고 목록·초점 ID를 유지한다. | 통과 |
| UX-02 | 유형 그림은 장식이며 제목/안내/상태가 뜻을 전달한다. 애매한 분류는 기본그림으로 오해를 줄인다. | 통과 |
| UI-01 | details 내 취소·disabled·불확실 쓰기 잠금을 유지한다. 취소 후 todo 제목으로 기존 초점을 되돌린다. | 통과 |
| UI-02 | native summary/label/button과 가시 초점, 전체 텍스트 및 접힘의 상태 접근성을 유지한다. | 통과 |

보완 착수: 6개 관점 통과, 미해결 P0/P1 없음. 공통 재질/폰트의 최종 비교는 부모 변경 반영 뒤 판정한다.

390px 사후 화면에서 현황 숫자의 줄바꿈이 두 칸에서 달랐다. WD-01/WD-02는 같은 기준선과 좁은 폭의 공간 부족, UX-01/UX-02는 두 수치의 비교와 빠른 이해, UI-01/UI-02는 읽기 순서/전체 텍스트 유지를 각각 확인했다. 480px 이하에서 양쪽 숫자를 라벨 아래 같은 줄에 배치하는 최소 CSS 보완은 6개 관점 통과다. 확인은 320/390px 실제 화면과 두 자릿수/확대 상태로 한다.

## 최종 사후 검토

실제 IAB 1536×1024에서 기준 이미지와 비교했다. 공통 목재/양피지 bitmap과 실제 desk/book sprite, 20px 본문/48px 제목/큰 초록 CTA가 연결됐으며, 본문 미션 카드 높이는 약297px다. 공통 담당이 헤더의 투명 아이콘 셀 점유를 줄여 높이를134→102px로 보완했다. 완료 미션은 가로 요약과 내용·취소 details로 제공한다. 시안의 임의 건수/날짜를 흉내내지 않고 서버 상태 의미를 표시하므로 지난 완료 건수, 날짜 범위와 추가 안내는 시안과 다르다. 초기 P2 공통 재질 미반영은 해결됐다.

| 관점 | 실제 결과와 근거 | 판정 |
|---|---|---|
| WD-01 | 동일1536 화면에서 배경·목재·종이·큰 삽화·CTA·완료 요약의 위계를 확인했다. 기능은 공통 컴포넌트/토큰의 실제 재질을 사용한다. | 통과 |
| WD-02 | 320/360/390/768/1280/1536px 캡처를 확인했다. 768 이하1열, 1280 이상2열이며 전체 가로 넘침이 없다. 200%390px에서 완료 행 압축을 발견해 관리 영역을 별도 행으로 수정했다. | 통과 |
| UX-01 | 마을 복귀·다시 진입·브라우저 back/forward에서 자동 본인 조회와 제목 초점을 확인했다. 완료 details에 내용·날짜·취소·마지막 변경을 유지했다. | 통과 |
| UX-02 | 상태는 문구/아이콘으로 구분하며 그림은 장식이다. 빈 목록, pending, 저장 응답 유실과 복구를 확인했다. 두 자릿수40/20 현황도 자연 줄바꿈한다. | 통과 |

| UI-02 | 실제 키보드와 제목/오류/새로고침 초점, 200% root 글자, 확대된 details/취소 버튼을 확인했다. 가로 넘침 수치뿐 아니라 실제 캡처도 검토했다. | 통과 |

증거: `assets/today-tasks-reference-aligned-1536.png`, `today-tasks-common-{320,360,390,768,1280,1536}.png`, `today-tasks-common-text-200-390.png`. 자동 연결과 오류 증거는 별도 자동 연결 검토에 기록한다.
