# 전문가 검토 기록: 월드 상호작용 E 배지 삭제

## 검토 정보

- 날짜·범위: 2026-10-30. 장소 표지의 근접 상태와 하단 상호작용 버튼에 붙은 E 배지를 삭제한다.
- 수행 주체·방식: 보조 대화의 `/root` 한 에이전트가 6개 가상 프로파일로 검토했다. 이 대화의 도구 제한으로 서브 에이전트는 사용하지 않았다. 외부 전문가 자문이 아니다.
- 자료: 사용자 요청, 전문가 운영 지침·6개 프로파일·검토 양식, `StudentClassroom.tsx`, `student-world.css`, 기존 `2026-10-30-world-object-interaction.md`.
- 단계: 사전 설계. 구현 후 검증은 아래에 추가한다.

## 사용자와 설계안

- 과업: 캐릭터 이동 → 가까운 건물 클릭 또는 상호작용 버튼 → 목적지 페이지. 반복되는 E 장식이 필요 없다는 사용자 보고가 변경 이유다.
- 구성: 기존 마을·장소 표지·상태 안내·상호작용 버튼·이동 컨트롤 구조를 유지한다. 가까운 표지의 E 글자와 하단 버튼의 E 키 모양만 제거한다. 원거리 이동 화살표는 유지한다.
- 상태: 원거리/이동 중/근접/비활성/활성/초점에서 기존 조건·문구·동작을 유지한다. E·Enter 단축키와 도움말·접근 가능한 이름은 유지한다. 저장·오류·최대 목록은 이번 표시 변경에 해당하지 않는다.
- 반응형: 기존 360/390/768/1280px 배치와 최소 버튼 높이를 유지한다. 삭제로 텍스트나 조작 영역을 숨기지 않는다. 체크박스·열 구성·페이지 정보 구조는 변경 대상이 아니다.

## 구현 후 실제 검증

- `StudentClassroom.tsx`: 근접 표지의 E span을 제거하고 원거리에서만 이동 화살표를 표시한다. 하단 버튼은 ‘상호작용’ 텍스트만 남겼다. 사용하지 않는 `.world-key-hint` CSS를 제거했다.
- `web/npm run build` 통과(TypeScript 및 Vite, 118 modules). 기존 500kB 초과 번들 경고는 유지된다. `git diff --check` 통과.
