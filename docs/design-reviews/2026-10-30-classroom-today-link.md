# 전문가 검토 기록: ‘오늘 할 일’ 외부 링크 연결

## 검토 정보

- 날짜 / 대상 설계 버전 또는 커밋: 2026-10-30 / 학급 공간의 오늘 할 일 장소 연결 변경
- 요청과 변경 범위 / 범위 밖 항목: 2D 학급 공간의 ‘오늘 할 일’ 장소를 펼침 패널에서 사용자가 지정한 `https://schooldoc-nine.vercel.app/s/missions/b98b324f-fedf-4f70-b259-e048159f69e5`로 이동하는 링크로 바꾼다. 링크 대상 서비스의 화면이나 코드는 범위 밖이다.
- 수행 주체·방식: Codex 한 에이전트가 여섯 가상 프로파일의 기준을 개별 적용했다. 외부 전문가 자문은 없었다.
- 입력 자료: 이번 사용자 요청, `web/src/StudentClassroom.tsx`, `docs/design-reviews/2026-10-30-class-space-main.md`, 전문가 운영 지침 및 6개 프로파일
- 검토 단계: 사전 설계

## 사용자와 설계안

- 대상 사용자·이용 환경·핵심 과업: 학급 공간에서 ‘오늘 할 일’을 선택해 오늘 미션 화면으로 이동한다.
- 현재 문제와 재현 조건: 현재 장소 버튼은 기존 오늘 활동 패널을 펼친다. 사용자는 해당 장소를 지정한 Schooldoc 미션 URL로 연결해 달라고 요청했다.
- 페이지·섹션 구성과 이동 경로: 학생 공간 → ‘오늘 할 일’ 링크 → 사용자가 제공한 URL. 새 탭을 강제하지 않고 링크의 기본 동작으로 같은 탭에서 이동한다.
- 각 화면의 목적·주요 행동·저장 범위: 이 변경은 기존 패널 대신 명시된 목적지로 이동한다. 데이터 저장·API는 변경하지 않는다.
- 기본·빈 상태·로딩·오류와 복귀: 브라우저의 일반 링크 이동을 사용한다. 목적지 로딩·오류·돌아가기는 브라우저 및 목적지 서비스가 처리한다.
- 반응형·긴 텍스트·키보드 설계: 기존 장소 카드의 크기·라벨·반응형 배치를 유지한다. 링크는 Tab/Enter로 이동 가능하고 새 탭 표시를 가장하지 않는다.

- 수정 후 6개 관점 재판정: 구현 후 기존 카드 외형·명확한 링크 의미·정확한 href를 확인한다.
- 착수 판정·시점: 2026-10-30, 여섯 관점 모두 통과, 미해결 P0·P1 없음. 구현 착수 가능.
- 남긴 P2·P3 처리: P2-01 목적지 페이지 본문은 이 도구에서 접근 불가. 링크 대상은 사용자가 지정했으며 구현 후 주소가 정확한지 확인한다.
