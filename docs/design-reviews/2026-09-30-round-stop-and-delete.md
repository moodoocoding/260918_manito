## 1. 요구사항 및 현재 문제 진단

1. **진행 시즌 자세히 보기 클릭 시 제어 버튼 미노출 (UX 단절)**:
   - 교사가 `운영 요약` 화면에서 `"진행 시즌 자세히 보기"` 버튼을 누르거나 좌측 메뉴에서 `"시즌 설정"`을 누르면 `view === "rounds"`로 이동하지만, 선택된 시즌(`chosen`)이 비어 있어 시즌 제목만 적힌 목록 버튼이 먼저 표시된다.
   - 교사는 다시 한 번 시즌 제목을 눌러야만 `시즌 진행 관리`(`일시정지`, `활동 종료`, `시즌 취소`) 버튼이 나타나므로, 시즌을 중지하거나 삭제하는 기능이 없다고 느끼게 된다.
2. **시즌 완전 삭제(`deleteRound`) 기능 부재**:
   - 현재 `changeRoundStatus`는 `pause`, `resume`, `end`, `cancel`, `archive` 상태 전이만 지원하며, 실수로 시작했거나 테스트로 만든 시즌을 중지하고 완전히 지우는 `deleteRound` API와 UI가 없다.
   - 취소(`cancelled`)된 시즌도 목록에 계속 남아 학급 운영 화면을 어지럽히고, 진행 중인 시즌이 있으면 학급 삭제(`deleteClassData`)까지 막힌다.

## 2. 6인 전문가 관점별 사전 검토

### WD-01 · 시각 구성과 브랜드
- **판단**: 통과 (P0/P1 없음)
- **근거**:
  - `시즌 진행 관리` 영역(`round-lifecycle-box`) 내에서 일상적 진행 제어 버튼(`일시정지`, `재개`, `조건 확인`)과 파괴적 동작(`시즌 취소`, `시즌 중지 및 삭제`)을 기존 `.danger` 및 `.outline` 버튼 위계에 맞춰 일관되게 배치한다.
  - 시즌 목록에서도 각 항목이 단순 텍스트처럼 보이지 않도록 상태와 관리 안내를 명확히 구분한다.

### WD-02 · 반응형 레이아웃과 타이포그래피
- **판단**: 통과 (P0/P1 없음)
- **근거**:
  - `.round-lifecycle-box .action-row`는 `flex-wrap: wrap` 구조를 사용하므로 `"시즌 중지 및 삭제"` 버튼이 추가되어도 모바일·태블릿·데스크톱 폭에서 줄바꿈이 자연스럽게 유지되며 텍스트 잘림이나 가로 넘침이 발생하지 않는다.

### UX-01 · 정보 구조와 과업 흐름
- **판단**: 수정안 반영 후 통과
- **문제 → 근거 → 영향 → 수정안 → 확인 방법**:
  - **문제**: `운영 요약`에서 `"진행 시즌 자세히 보기"`를 클릭해도 `시즌 설정`의 목록 화면으로 이동해 한 번 더 시즌을 클릭해야 제어 버튼이 나타남.
  - **설계 근거**: 과업 연속성 원칙 — 교사가 "진행 시즌 자세히 보기" 또는 "시즌 설정"을 열었을 때는 현재 운영 중인 시즌(또는 준비 중인 최신 시즌)의 제어판이 즉시 열려야 클릭 수를 줄이고 혼란을 막을 수 있음.
  - **사용자 영향**: 교사가 시즌 중지·취소·삭제 버튼을 찾지 못해 시즌 제어가 불가능하다고 오해함.
  - **수정안**: `view === "rounds"` 진입 시 교사가 명시적으로 `"시즌 목록"` 버튼을 누른 경우가 아니면 `activeRound`(없으면 첫 번째 `ready`/`draft` 시즌)를 자동 선택(`selectRound`)해 즉시 `시즌 진행 관리` 패널을 노출한다. 상단 `"시즌 목록"` 버튼을 누르면 언제든 전체 시즌 목록으로 전환할 수 있게 한다.
  - **확인 방법**: `운영 요약` → `"진행 시즌 자세히 보기"` 클릭 시 즉시 현재 시즌의 상세 제어 화면과 중지/삭제 버튼이 표시되는지 확인.

### UX-02 · 인지 부담과 사용자 이해
- **판단**: 수정안 반영 후 통과
- **문제 → 근거 → 영향 → 수정안 → 확인 방법**:
  - **문제**: `"시즌 취소"`(기록을 남기고 상태만 취소로 변경)와 `"시즌 중지 및 삭제"`(시즌 기록과 배정을 완전히 제거)의 차이가 모호할 수 있음.
  - **설계 근거**: 파괴적 작업의 결과를 명확한 한국어로 사전 안내해야 실수를 방지할 수 있음.
  - **수정안**: 진행/일시정지/공개대기 상태에서는 버튼명을 `"시즌 중지 및 삭제"`, 준비/취소/보관 상태에서는 `"시즌 삭제"`로 표시하고, 확인 대화상자(`ConfirmDialog`)에서 `"배정·미션·쪽지 기록을 모두 삭제하고 진행 상태를 해제합니다. 삭제한 시즌은 복구할 수 없어요."`라고 명확히 안내한다.
  - **확인 방법**: 확인 모달 문구와 실행 후 완료 안내 메시지(`"시즌을 중지하고 삭제했어요."`) 확인.

### UI-01 · 조작과 컴포넌트 상태
- **판단**: 통과 (P0/P1 없음)
- **근거**:
  - 삭제 요청 중에는 `busy` 상태로 모든 제어 버튼과 확인 모달 버튼을 비활성화하여 중복 클릭을 막고, 서버에서도 `requestId` 기반 멱등성(`commands/{requestId}`)을 보장한다.
  - 삭제 직후 선택된 시즌(`chosen`, `chosenRef.current`)과 요약 상태를 초기화하고 최신 시즌 목록을 다시 불러온다.

### UI-02 · 접근성과 화면 품질
- **판단**: 통과 (P0/P1 없음)
- **근거**:
  - 기존 `ConfirmDialog` 컴포넌트를 그대로 사용하여 포커스 이동, 키보드 조작, `role="alert"` / `role="status"` 알림 영역과의 호환성을 유지한다.

## 3. 종합 결론 및 사후 검토
- **사전 검토**: 6개 전문가 관점 사전 검토 결과 미해결 P0·P1 문제 없음.
- **구현 후 사후 검토**:
  - **WD-01 / WD-02**: `시즌 진행 관리` 영역과 `지난 활동` 카드에 `.danger.outline` 스타일의 `"시즌 중지 및 삭제"` / `"시즌 삭제"` 버튼이 자연스럽게 배치되었으며, 모바일·데스크톱 폭에서 줄바꿈과 여백이 안정적임을 확인.
  - **UX-01 / UX-02**: `운영 요약`에서 `"진행 시즌 자세히 보기"`(또는 `"준비 중인 시즌 열기"`) 클릭 시 즉시 해당 시즌이 선택되어 `일시정지`, `활동 종료`, `시즌 취소`, `시즌 중지 및 삭제` 버튼이 바로 노출됨. 상단 `"시즌 목록"` 버튼으로 언제든 전체 목록으로 돌아갈 수 있음.
  - **UI-01 / UI-02**: 삭제 전 `ConfirmDialog`를 통해 영구 삭제 안내와 중복 클릭 방지가 작동하며, 삭제 완료 후 `activeRoundId` 해제·`roundSettings` 및 하위 컬렉션 재귀 삭제·`pairHistory` 복원이 정상 수행됨.
- **검증**: `npm run build`, `npm run test:functions` (12건), `tests/entry-card-qr.test.mjs` (1건) 모두 통과.
