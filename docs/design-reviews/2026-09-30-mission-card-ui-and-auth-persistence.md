## 1. 사전 요구사항 및 문제 진단

### 문제점
1. **학생 홈 화면 미션 카드 혼잡성**:
   - `핵심 과업 · 이번에 해볼 미션` 뱃지와 `이번에 해볼 미션` h3가 중복되어 시각적으로 번잡함.
   - 불필요한 `이 미션 쉬기` 버튼이 제공되어 "안 하면 쉬는 건데 굳이 눌러야 하나?"라는 혼란 유발.
   - 현재 해야 할 미션 확인과 미션 변경/탐색 간의 워크플로우가 홈 화면 내에서 모호하게 섞여 있음.
2. **새로고침 시 로그아웃 문제**:
   - `firebase.ts`에서 학생 로그인이 `inMemoryPersistence`로 강제되어 있어, F5 새로고침 시 메모리 증발로 즉시 로그인 세션이 끊김.
3. **자동 로그인(로그인 기억하기) 부재**:
   - 개인 태블릿이나 가정용 PC에서 사용하는 학생도 매번 긴 학급 코드와 4자리 개인 코드를 다시 입력해야 하는 불편함 존재.

## 2. 6개 관점 개별 검토 및 판단

### WD-01 · 시각 구성과 브랜드
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 미션 카드 상단 중복 라벨을 `💌 오늘의 미션`으로 단일화하고, 카테고리 뱃지만 깔끔하게 우측에 배치하여 카드 상단 위계를 명료하게 정돈함.
  - 메인 버튼 `[✨ 해냈어요!]`(초록 primary-cta)와 `[다른 미션으로 바꾸기 →]`(중립 outline)의 색상 및 대비를 분리하여 과업 우선순위를 한눈에 알 수 있게 함.
  - 로그인 화면의 `이 기기에서 로그인 기억하기` 체크박스는 산뜻한 민트/에메랄드 테마와 통일된 체크박스 스타일을 적용함.

### WD-02 · 반응형 레이아웃과 타이포그래피
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 모바일 360px~480px 화면에서 두 버튼(`[해냈어요!]`, `[다른 미션으로 바꾸기 →]`)이 줄바꿈되거나 답답하게 찌그러지지 않도록 `gap: 0.6rem`, flex-wrap을 적절히 적용하고 터치 타깃 44px 이상을 확보함.
  - 로그인 폼의 체크박스는 텍스트 라벨과 세로 정렬(aligned center) 및 충분한 터치 영역(클릭 패딩)을 부여함.

### UX-01 · 정보 구조와 과업 흐름
- **판단**: 통과 (개선안 반영)
- **근거**:
  - **홈 화면 vs 미션 탭의 역할 분리**:
    - 홈 화면은 "오늘의 미션 확인 및 완료 인증"에 집중.
    - 미션을 교체하거나 다른 미션을 둘러보고 싶을 때는 `[다른 미션으로 바꾸기 →]` 버튼을 눌러 전체 [미션] 탭으로 매끄럽게 연결.
  - 불필요한 `[이 미션 쉬기]` 버튼은 삭제하여 과업 결정을 간소화함(미션을 안 하면 패널티 없이 넘어가는 마니또 규칙과 일치).

### UX-02 · 인지 부담과 사용자 이해
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 초등학생이 "이 미션 쉬기 버튼을 누르면 혼나거나 감점되나?" 하고 걱정할 필요를 원천 차단함.
  - 실수로 F5나 화면을 새로고침해도 세션이 유지되어 재입력 공포를 없앰.
  - 학교 컴퓨터실 등 공용기기에서는 체크박스를 해제(기본값) 상태로 로그인하면 브라우저 탭/창을 닫을 때 즉시 세션이 안전하게 종료(`browserSessionPersistence`)되어 개인정보 및 비밀친구 보안 유지.
  - 개인 기기에서는 `이 기기에서 로그인 기억하기`를 체크하면 브라우저를 닫았다 열어도 바로 홈으로 진입(`indexedDBLocalPersistence` / `browserLocalPersistence`).

### UI-01 · 조작과 컴포넌트 상태
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 버튼 누름 시 `busy` 상태에 맞춰 비활성화 및 로딩 피드백 제공.
  - `[다른 미션으로 바꾸기 →]` 클릭 시 `onNavigate("missions")` 트리거로 탭 전환.
  - 체크박스 클릭 및 라벨 클릭 시 즉각적인 체크 상태 토글.

### UI-02 · 접근성과 화면 품질
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 체크박스에 명시적 `id="student-remember-me"`와 `<label htmlFor="student-remember-me">`를 결합하여 키보드 스페이스바 토글 및 스크린리더 인식 보장.
  - 미션 카드 내 버튼들에 포커스 링(focus-visible) 유지.

## 4. 구현 후 6개 관점 재검토 결과

1. **WD-01 (시각 구성과 브랜드)**: 통과. 중복 헤더가 정리되어 `💌 오늘의 미션`과 카테고리 뱃지만 단정하게 상단에 노출되고, 미션 텍스트 및 완료/교체 액션 버튼의 시각적 위계가 완벽히 확립됨.
2. **WD-02 (반응형 레이아웃과 타이포그래피)**: 통과. 모바일 폭(360px)에서 버튼들이 유연하게 줄바꿈되며, 로그인 폼의 체크박스는 44px 이상의 터치 타깃을 확보하여 실수 없는 조작 가능.
3. **UX-01 (정보 구조와 과업 흐름)**: 통과. 홈 화면은 "오늘의 미션 확인 및 완료"에 집중하고, 미션 교체/탐색은 [미션] 탭으로 위임하는 일관된 단방향 흐름 완성.
4. **UX-02 (인지 부담과 사용자 이해)**: 통과. "이 미션 쉬기"라는 불필요한 선택지가 제거되어 초등학생의 고민과 죄책감 부담 해소. 새로고침 시에도 세션이 유지되며, 개인 기기에서는 자동 로그인 지원으로 편의성 대폭 개선. 공용기기에서는 체크 해제 시 창을 닫으면 자동 세션 만료로 보안 유지.
5. **UI-01 (조작과 컴포넌트 상태)**: 통과. `[✨ 해냈어요!]` 완료 액션과 `[다른 미션으로 바꾸기 →]` 네비게이션 액션의 상태 및 피드백 정상 동작 확인.
6. **UI-02 (접근성과 화면 품질)**: 통과. 체크박스-라벨 매핑(`student-remember-me`), 키보드 포커스 링, 웹 빌드 정상 통과.
