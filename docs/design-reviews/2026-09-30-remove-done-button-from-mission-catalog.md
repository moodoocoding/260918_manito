# 6인 전문가 검토 기록: 미션 골라보기 목록 내 오조작 유발 '해냈어요' 버튼 제거 및 홈 화면 전용화

- **일자**: 2026-09-30
- **대상 기능**: 미션 골라보기 화면(`view === "missions"`)에서 '해냈어요' 버튼 제거, 도전 미션 선택(`이번에 해볼래요`) 전용화 및 홈 화면 단일 완료 체계 확립
- **관련 파일**: `web/src/StudentRound.tsx`

---

## 1. 개요 및 요구사항

### 현황 및 문제점
1. **역할 혼선 및 오조작 발생**:
   - '미션 골라보기' 화면은 미션 후보들을 탐색하고 도전할 미션을 고르는 탐색 공간인데, 여기에 즉시 완료 버튼(`✨ 해냈어요!`)이 함께 노출되어 있어 학생이 미션을 고르다 실수로 완료해 버리는 문제(예: 강서윤 학생 오조작)가 발생함.
2. **단일 과업 원칙 위배**:
   - 미션 완료는 '홈' 화면의 '오늘의 미션' 카드에서 수행하는 것이 자연스러운 흐름이며, 탐색 목록에서 무분별하게 완료 버튼이 노출되는 것은 기능 과잉 및 실수 유발 요인임.

### 개선 방향
1. **미션 골라보기 목록 카드 액션 정리**:
   - 미완료 미션 카드: 오직 `[이번에 해볼래요]` 버튼만 노출.
   - 현재 도전 중인 미션 카드: `🎯 지금 도전 중` 뱃지만 노출 (버튼 불필요).
   - 완료된 미션 카드: `✓ 완료됨` 비활성 라벨 노출.
2. **미션 완료 권한 집중**:
   - 미션 완료(`✨ 해냈어요!`)는 오직 **홈 화면의 '오늘의 미션' 카드**에서만 가능하도록 단일화.

## 2. 6개 전문가 관점 사전 검토

### WD-01 · 시각 구성과 브랜드
- **판단**: 승인
- **근거**: 미션 카드 하단의 액션 영역이 간결해져 카드의 크기와 높이가 일정하게 유지된다. 원색적인 완료 버튼이 사라져 탐색 목록 본연의 시각적 안정감을 회복한다.

### WD-02 · 반응형 레이아웃과 타이포그래피
- **판단**: 승인
- **근거**: 모바일 환경에서 각 카드 하단에 2개의 버튼이 옹기종기 붙어 터치 실수를 유발하던 문제가 해소된다. 단일 버튼 또는 상태 라벨만 위치하므로 터치 타깃이 명확해진다.

### UX-01 · 정보 구조와 과업 흐름
- **판단**: 승인
- **근거**:
  - `[미션 골라보기]` = **선택(탐색)** 과업 (`이번에 해볼래요`)
  - `[홈]` = **실천 및 확인(완료)** 과업 (`오늘의 미션` → `✨ 해냈어요!`)
  - 각 화면의 목적과 액션이 1:1로 명확히 매핑되어 사용자 여정이 단순하고 예측 가능해진다.

### UX-02 · 인지 부담과 사용자 이해
- **판단**: 승인
- **근거**: "미션을 고르려다 완료를 눌러버리는" 돌이킬 수 없는 실수를 인터페이스 레벨에서 원천 차단한다. 학생은 안심하고 미션 목록을 스크롤하며 둘러볼 수 있다.

### UI-01 · 조작과 컴포넌트 상태
- **판단**: 승인
- **근거**:
  - 미션 골라보기 카드의 인터랙션이 `선택하기(이번에 해볼래요)` 단일 액션으로 축소됨.
  - 선택 시 즉시 홈 화면의 오늘의 미션으로 지정되며, 홈으로 이동하여 안전하게 완료를 누르도록 유도.

### UI-02 · 접근성과 화면 품질
- **판단**: 승인
- **근거**: 불필요한 완료 버튼 제거로 키보드 탭 순서(Tab Order)가 간결해지고, 스크린리더 사용 시에도 혼란스러운 중복 조작 인터페이스가 제거된다.

## 4. 구현 후 6개 전문가 관점 사후 검증

- **WD-01 (시각 구성)**: 미션 카드 하단 버튼 수가 1개로 균일해져 카드 목록의 시각적 리듬과 정돈감이 크게 향상됨.
- **WD-02 (반응형 레이아웃)**: 모바일 뷰포트에서도 버튼 줄바꿈이나 터치 타깃 겹침 없이 쾌적하게 렌더링됨.
- **UX-01 (정보 구조)**: [미션 골라보기 → 이번에 해볼래요]와 [홈 → 오늘의 미션 → 해냈어요]의 역할 분담이 확실해짐.
- **UX-02 (인지 부담)**: 실수로 미션 목록에서 완료를 누르는 오조작 가능성이 0%로 제거됨.
- **UI-01 (조작 상태)**: 도전 중인 미션에는 `도전 중인 미션` 상태 라벨, 완료된 미션에는 `✓ 완료됨` 라벨이 정확히 표시됨.
- **UI-02 (접근성 품질)**: 불필요한 중복 액션 제거로 포커스 탐색 경로가 단순화됨.
- **최종 검증**: 빌드 및 테스트(TypeScript, Vite, Functions Unit Tests, QR Test) 전원 통과.
