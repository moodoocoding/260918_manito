## 사용자와 설계

- 사용자·과업: 담당 교사가 시즌의 전체 배정을 안전하게 확인하고 한 학생이 한 명을 맡고 한 명에게 맡겨졌는지 판단한다. 학생에게는 이 페이지와 전체 배정 정보를 제공하지 않는다.
- 현재 문제: 배정표 버튼이 시즌 상세 하단에 묻혀 있다(코드 확인). 기존 서버 매칭은 일대일 순열이나 조회 응답의 무결성 검사는 없다(코드 확인). 실제 운영 중 손상 사례는 확인하지 못했다.
- 구조: 교사 메뉴의 `시즌 설정` 다음에 `배정 확인` 페이지. 시즌 선택 → 명시적 `배정표 보기` → 참가자 수·배정 수·고유 수신자 수 및 학생별 `맡은 친구`/`나를 맡은 친구` 표 → `가리기`. 시즌 설정 상세에는 전용 페이지 이동 버튼만 둔다.
- 상태: 시작 전에는 배정 전 안내, 목록 로딩·실패·재시도, 열람 중·오류, 정상 결과를 분리한다. 비정상 저장 데이터는 서버가 응답을 거절하고 안내한다. 페이지 이탈·탭 숨김·5분 경과에 표를 가린다. 재진입은 다시 열람한다.
- 반응형: 표는 작은 화면에서 행별 카드로 재배치한다. 긴 가상 이름은 줄바꿈, 40명은 자연스러운 세로 스크롤. 360·390·768·1280px, 확대, 키보드 초점과 오류를 구현 후 확인한다.
