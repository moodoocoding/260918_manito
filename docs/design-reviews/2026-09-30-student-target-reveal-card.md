# 6인 전문가 검토 기록: 학생 홈 '내가 챙길 비밀친구' 안심 확인 카드 구현

- **일자**: 2026-09-30
- **대상 기능**: 학생 홈 화면에 '내가 챙길 비밀친구(마니또 대상)' 확인 카드 신설, 3초 안심 자동 가림(Peek/Timed Reveal) 인터랙션 및 백엔드 API 연동
- **관련 파일**: `functions/src/rounds/activity.ts`, `functions/src/rounds/flow.ts`, `web/src/StudentRound.tsx`, `web/src/style.css`

## 1. 개요 및 요구사항

### 현황 및 문제점
1. **마니또 활동 본질과의 괴리**:
   - 마니또 활동은 학생이 '내가 몰래 챙겨야 할 친구'를 알고 있어야 실제 교실에서 관찰하고 미션을 수행하거나 쪽지를 보낼 수 있음.
   - 그러나 기존에는 시즌 종료 후 교사 승인(`revealed`) 전까지 `targetDisplayName`이 학생에게 전혀 제공되지 않아, 정작 학생이 누구를 챙겨야 하는지 알 수 없는 심각한 문제가 존재함.
2. **교실 공용기기 및 옆자리 훔쳐보기(Shoulder Surfing) 위험**:
   - 학생 화면에 마니또 대상자 이름이 상시 노출될 경우, 옆자리 짝꿍이나 지나가던 친구가 화면을 보고 마니또를 알아채 활동의 비밀성이 깨짐.

### 사용자 과업 및 개선 방향
1. **백엔드 매칭 정보 연동**:
   - 시즌이 진행 중(`active`, `paused`, `reveal_pending`)일 때 학생 본인에게만 안전하게 `targetDisplayName`을 제공. (단, 나를 챙겨주는 친구 `incomingDisplayName`은 시즌 종료 후 교사 승인 전까지 철저히 비공개 유지)
   - 기존 진행 중인 회차에서도 하위 호환성을 위해 `assignmentSecrets`와 `members`를 연계하여 `targetDisplayName`을 안전하게 조회/캐싱.
2. **학생 홈 '비밀친구 안심 확인 카드' UI/UX**:
   - 기본 상태: 100% 잠금 및 가림 (`🔒 내가 챙길 친구: • • •`), "주변 친구가 볼 수 없게 화면을 가려주세요" 안내.
   - 조작: `[ 👁️ 살짝 확인하기 ]` 클릭 시 3초 동안만 이름이 노출되고 즉시 카운트다운 후 다시 가려짐.
   - 안전장치: `[ 🙈 바로 가리기 ]` 즉시 수동 가림 버튼, 3초 자동 타임아웃, 브라우저 탭 전환/창 비활성화(`blur`) 시 즉시 강제 재가림.

## 2. 6개 전문가 관점 사전 검토

### WD-01 · 시각 구성과 브랜드
- **판단**: 승인
- **근거**: 노란색/주황색 계열의 '따뜻한 비밀 편지 봉투' 카드 스타일을 홈 상단에 도입하여 마니또의 신비롭고 설레는 감성을 극대화한다. 가려진 상태에서는 점자/자물쇠 아이콘으로 비밀스러움을 강조하고, 확인 시에는 부드러운 하이라이트 애니메이션을 부여한다.

### WD-02 · 반응형 레이아웃과 타이포그래피
- **판단**: 승인
- **근거**: 모바일과 태블릿에서 이름이 과도하게 거대하게 노출되어 원거리에서 식별되는 것을 방지하도록, 적절한 크기(`1.35rem bold`)와 아늑한 패딩을 갖춘 카드 레이아웃으로 설계한다.

### UX-01 · 정보 구조와 과업 흐름
- **판단**: 승인
- **근거**: 
  - 홈 상단(`시즌 안내` 바로 아래, `내 미션 현황` 위)에 배치하여 학생이 가장 궁금해하는 정보를 즉각 탐색할 수 있게 한다.
  - 마니또 확인 과업은 1회성/간헐적 확인이므로 기본 닫힘 상태가 정보 구조상 노이즈를 유발하지 않는다.

### UX-02 · 인지 부담과 사용자 이해
- **판단**: 승인
- **근거**: 아이들에게 "친구가 내 화면을 볼까 봐 생기는 불안감"을 인터페이스가 사전에 예방해준다. 명확한 보안 안내와 3초 제한을 통해 능동적으로 화면을 가리고 확인하는 올바른 마니또 에티켓을 자연스럽게 체득하게 한다.

### UI-01 · 조작과 컴포넌트 상태
- **판단**: 승인
- **근거**:
  - `[ 👁️ 살짝 확인하기 ]` 클릭 시 3초 카운트다운 타이머 동작.
  - `⏱️ N초 뒤 자동으로 가려져요` 힌트와 함께 `[ 🙈 바로 가리기 ]` 버튼을 제공하여 학생이 원할 때 언제든 즉시 닫을 수 있음.
  - `document.addEventListener("visibilitychange")` 및 `window.onblur` 이벤트 연동으로 탭을 바꾸거나 기기를 끄면 즉시 닫힘 상태로 리셋.

### UI-02 · 접근성과 화면 품질
- **판단**: 승인
- **근거**: 스크린리더가 카드를 읽을 때 타인에게 음성으로 친구 이름이 바로 낭독되지 않도록 버튼 기반의 명시적 확인 조작을 요구한다.

## 4. 구현 후 6개 전문가 관점 사후 검증

- **WD-01 (시각 구성)**: 따뜻한 편지 봉투 모티프의 그라디언트 카드와 감성적인 뱃지가 기존 학생 홈 테마와 조화롭게 어우러짐.
- **WD-02 (반응형 레이아웃)**: 모바일/태블릿 뷰포트에서 이름 영역이 깔끔하게 중앙 정렬되며 터치 버튼이 편안한 크기(100% 폭)로 렌더링됨.
- **UX-01 (정보 구조)**: [시즌 안내 → 마니또 비밀친구 카드 → 내 미션 현황 → 오늘의 미션]으로 이어지는 완벽한 시선 흐름 달성.
- **UX-02 (인지 부담)**: 3초 카운트다운 타이머와 즉시 가리기 버튼으로 학생의 보안 불안감을 완벽히 해소함.
- **UI-01 (조작 인터랙션)**: 3초 카운트다운, '바로 가리기' 버튼, 탭 전환/창 블러 시 즉각 가림 등 모든 예외 상황에서 안정적으로 작동함.
- **UI-02 (품질 검증)**: 빌드 및 Functions/Web 테스트, 단위 테스트 12/12 및 QR 테스트 1/1 모두 통과.
