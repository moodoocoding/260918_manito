# 전문가 검토 기록: 마을을 오른쪽으로 확장하고 건물 4개 추가

## 검토 정보

- 날짜/요청: 2026-10-30. 사용자는 서브 에이전트 활용, 오른쪽으로 더 긴 마을과 추가 건물 약 4개를 요청했다.
- 범위: 기존 네 장소와 도트 아트는 보존하고, 오른쪽 동쪽 구역을 이어 총 여덟 건물을 제공한다. 새 네 기능은 미정이므로 ‘새 공간 1~4 / 준비 중’ 페이지로 연결한다. 실제 새 업무·API·데이터는 추가하지 않는다.
- 수행: `/root`가 여섯 가상 프로파일을 개별 적용했다. `/root/town_extension_art`는 도트 아트/배치, `/root/east_flow_review`는 좌표·이동·라우트 읽기 검토를 수행한다. 외부 인간 전문가 참여는 없다.
- 자료: 사용자 요청, 현재 월드/이동 hook/라우트/미리보기, 전문가 운영 지침·여섯 프로파일, React 품질 및 전체 흐름 검증 스킬. 이미지 생성 전 검토는 별도 아트 기록을 참조한다.

## 설계·상태·반응형

- 과업: 기존 마을에서 오른쪽으로 걸어 동쪽 구역 탐색 → 새 건물 앞으로 이동 → 건물/상호작용 버튼 → 준비 중 공간 확인 → 마을 복귀.
- 기존 2:1 맵 오른쪽에 같은 크기의 새 도트 맵을 배치한다. 사용자의 추가 설명을 반영해 모든 기기에서 장면 폭은 실제 보이는 지도 뷰포트의 정확히 200%/비율 4:1이다. 한 화면에 여덟 건물을 압축하지 않는다. 모바일 표지는 48px 이상 높이의 간결한 이름 표지로 재배치하고 지도 내부만 가로 탐색한다.
- 월드 좌표를 0~200 단위로 바꾼다. 기존 16/40/65/87 좌표·이동 속도(24단위/초)·근접 범위(6단위)는 유지한다. 동쪽은 100+로컬 좌표다. 이미지/아바타/표지/클릭영역/길 클릭을 동일 좌표계로 변환한다. 이동 한계는 5~195다.
- 초기 설계의 ‘서쪽/동쪽 마을’ 표지와 보행 바로가기는 사용자의 후속 삭제 지시로 제거했다. [별도 여섯 관점 검토](2026-10-30-world-remove-extra-chrome.md)에 따라 긴 지도·카메라 추적·기존 방향 조작으로 탐색한다. 순간이동이나 원거리 즉시 입장은 만들지 않는다.
- 새 건물 표지는 미정 기능을 추측해 확정하지 않는다. 각 ‘새 공간’은 준비 중 상태를 명시하고 마을로 복귀할 수 있다. 실제 App·미리보기는 같은 ID/메타데이터를 사용한다.
- 상태: 걷는 중/근접/상호작용 가능/준비 중 공간/복귀. 현재 입장 중 위치만 메모리에 보존하고 로그아웃에서 초기화한다. 기존 목적지·Schooldoc URL·도움/로그아웃을 유지한다.
- 키보드/터치: 기존 방향키/A·D·길 클릭·건물 선택·E/Enter·48px 컨트롤, 모션 감소와 페이지 제목 초점을 유지한다. 장거리 자동 보행도 중도 방향 입력/포인터 해제로 제어할 수 있다.

- 수정안을 설계에 반영해 여섯 관점 모두 통과. 미해결 P0·P1 없음으로 구현 착수 가능.
- 읽기 검토 에이전트는 길 클릭 배율·아바타/표지/영역 변환·두 이동 한계·실제 App의 세 라우트 파서 및 미리보기 일치를 필수 확인으로 권고했다. 구현에서 반영한다.
