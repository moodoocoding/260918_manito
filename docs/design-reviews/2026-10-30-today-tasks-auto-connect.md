# 전문가 검토 기록: 로그인 이름으로 오늘 할 일 자동 연결

## 검토 정보

- 날짜: 2026-10-30. 수행: Codex 한 에이전트가 여섯 가상 역할을 개별 적용했다. 외부 전문가 검증은 아니다.
- 요청: 사용자가 이중 로그인을 지적하고 현재 한 학급만 사용하며 동명이인이 없다고 확인했다.
- 자료: 전문가 운영 지침/여섯 프로파일/양식, StudentTodayTasks, getStudentHome, Schooldoc GitHub main의 classMissionsServer/classMissions 계약. 원본 서비스 변경·실제 학생 조회·배포는 범위 밖이다.

## 요구와 설계

월드 진입에서 확인된 본인 학생 이름을 사용해 오늘 할 일을 자동 조회한다. 실제 조회·저장 직전에 기존 getStudentHome으로 세션·카드 버전·소속을 재검증하고 반환된 최신 displayName만 자격으로 사용한다. Schooldoc 기존 token+studentName/code 요청 계약과 원본 화면/서버는 유지한다. 본인 이름은 이미 로그인 과정에서 얻으며 다시 입력하지 않는다. 공용기기 정리·요청 취소·늦은 응답 차단·불확실 저장 잠금은 유지한다.

화면 순서: 공통 헤더 → 미션 문맥 → 자동 연결 상태 → 미션 목록. 실패하면 ‘다시 불러오기’와 선생님 도움/마을 복귀를 제공하고 다른 이름 입력이나 유사 이름 자동 탐색은 제공하지 않는다. 숨김/복귀에서는 기록을 지운 뒤 본인 세션을 재검증해 자동 조회한다. 사용자가 명시적으로 미션 연결을 끝내면 자동 재연결하지 않고 재열기 버튼만 제공한다. 저장 직전 검증된 이름이 목록 조회 당시와 다르면 저장을 중단하고 목록 재조회를 요구한다.

기본/로딩/오류/빈 목록/완료/취소/불확실 저장을 구분하고, 목록 진입 때 제목, 오류 때 오류 영역, 완료/취소 때 해당 미션 제목으로 초점을 옮긴다. 320/390/768/1280/1536px, 200% 글자, 긴 제목/설명·60개 항목을 확인한다. 확대 시 compact 행의 고정 두 열로 제목이 한 글자씩 세로 배치되는 문제는 관리 details를 별도 행으로 보내고 제목/배지는 자연 줄바꿈하도록 바꾼다.

## 실제 검증

구현 후 검증 결과를 이어 기록한다.

- IAB 실제 preview를 main과 같은 React StrictMode로 실행했다. 추가 클릭/입력 없이 목록 표시, 입력 요소0개, 제목 초점, 마을 복귀/Enter 재진입, back/forward 재진입을 확인했다.
- 오류 fixture는 자동 조회1회 실패 → 오류 초점 → 다시 불러오기로 정상 목록을 확인했다. 학생명 불일치 fixture는 미션0개·다른 학생명 화면 노출 없음으로 차단했다.
- 완료 표시 후 해당 제목 초점 → Enter로 내용·취소 열기 → 완료 취소 후 원래 목록/제목 초점을 확인했다. 수동 연결 종료 후 자동 조회가 재시작되지 않고 종료 제목으로 초점이 이동하며, 재열기 버튼으로 자동 조회한다.
- 가상 저장 응답 유실에서는 모든 완료/취소가 잠기고 새로고침 후 pending 상태와 최신 현황이 반영되며 초점이 새로고침 버튼으로 돌아왔다.
- 320/360/390/768/1280/1536px 및390px root 글자16→32px에서 실제 캡처와 재배치/전체 텍스트/조작을 확인했다. compact행을 별도 관리 행으로 바꿔 확대 때 제목·배지가 한 글자씩 세로로 밀리던 문제를 해결했다.
- 자동 연결로도 60개·제목100자·설명1000자, 현황40/20을 확인했다. 모바일의 긴 제목 옆 삽화는 위에 정렬해 제목 중간에 뜨던 여백을 줄였다. 브라우저 error/warn 로그는0개였다.

자동 API/수명주기 검사9개 통과. 숨김/pagehide/BFCache 정리는 기존 자동 이벤트 검사로 확인했다. pagehide 때 재조회하지 않고 visible/pageshow 뒤 재검증하도록 재개 gate를 넣었다. IAB의 실제 탭 숨김은 재현하지 못해 자동 모드의 물리적 탭 숨김/복귀는 미확인이다. 등록 이름 변경 직전 쓰기 차단은 코드로 확인했으며 실제 Firebase 이름 변경/카드 차단 세션·운영 조회/저장·화면 읽기/실기기/학생 사용성은 실행하지 않았다. 로컬 가상 흐름의 완료이며 운영 배포 검증으로 표현하지 않는다.
