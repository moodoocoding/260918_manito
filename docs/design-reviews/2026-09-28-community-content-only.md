# 전문가 검토 기록: 우리 반 소식의 안전한 첫 버전

## 검토 정보

- 날짜/범위: 2026-09-28, 개발 계획 v2.3 §6.9~6.10의 SE-3 중 검토된 배려 예시와 교사 안내. 학급 전체 실천 숫자는 비활성화한다.
- 수행: Codex 한 에이전트의 여섯 가상 역할 검토. 실제 외부 전문가·교사·학생 참여 없음.
- 자료: [기존 학생 경험 검토](2026-09-28-student-experience-plan.md), 개발 계획 §6.9~6.10, `TeacherRounds.tsx`, `StudentRound.tsx`, Firebase 권한·삭제 코드.

## 사용자와 설계안

- 학생 과업: 비교나 친구 추정 없이 배려 활동의 아이디어를 얻고, 선생님의 짧은 공지를 읽는다. 교사 과업: 시즌별로 140자 이하 평문 안내를 초안→미리보기→게시/내리기한다.
- 숫자 위협 검토: 10명·기여자 5명·10건 기준에서도 학생은 본인 기록과 교실 관찰을 안다. 일 1회 10건 단위 묶음이 0→10 또는 10→20 경계를 넘으면 특정 날짜의 소수 행동을 추정할 수 있다. 4/9명은 숫자 미공개, 10/40명도 이 조건만으로 안전을 입증할 수 없다. 철회 전후 비교와 학교의 작은 모둠 특성이 추가 위험이다. 현재 수치 설계는 **미해결 P1**이므로 숫자 서버 기능을 구현·활성화하지 않는다.
- 페이지: 학생 `우리 반`은 검토된 예시 2개와 게시된 교사 안내 1개만 표시한다. 안내가 없으면 빈 카드 자체를 숨긴다. 집계 값·참가자 수·부족 이유·실시간 성공 알림은 응답과 화면에 없다.
- 교사: 시즌 설정의 현재 시즌 상세에 안내 편집을 둔다. `저장`은 학생에게 노출하지 않는 초안, `게시`는 현재 입력을 미리보기로 보여 준 뒤 공개, `내리기`는 즉시 미제공. 변경은 담당 교사 인증·요청 ID·감사 기록으로 보호한다.
- 상태: 조회 실패는 우리 반 영역만 재시도. 예시는 남긴다. 게시 실패는 기존 게시본 유지, 입력 보존. 취소·권한 상실·학급 삭제는 안내를 제공하지 않는다.
- 반응형: 320px에서 한 열, 긴 140자 문장과 200% 확대에서 자연 줄바꿈. 텍스트와 상태만으로 구분하고 키보드 버튼 사용 가능.

- 착수 판정: **숫자를 제외한 콘텐츠/안내 범위** 여섯 관점 통과, 미해결 P0/P1 없음. 숫자 기능은 별도 범위의 미해결 P1로 착수 불가. 실제 브라우저와 권한 테스트 후 재판정한다.

## 구현 후 검증

- 수행: 같은 Codex 에이전트가 여섯 가상 역할로 개발 배포의 가상 교사·학생과 로컬 권한 테스트를 다시 확인했다. 실제 전문가 참여는 없다.
- WD-01: 학생 `우리 반`의 두 예시와 게시 후 교사 안내 한 카드, 게시 전의 빈 안내 카드 부재를 실제 화면에서 확인했다.
- WD-02: 인앱 브라우저의 약 635px에서 35자 안내와 카드 줄바꿈·가로 넘침 없음을 확인했다. 뷰포트 재설정이 적용되지 않아 320/390/768/1280px와 140자 최대 길이 실화면은 미확인이다.
- UX-01: 교사 시즌 상세에서 초안 저장→학생 화면 미리보기→게시, 학생 `우리 반` 재진입 후 안내 표시를 확인했다. 교사 안전 업무 메뉴 순서는 유지됐다.
- UX-02: 학생 문구가 두 예시를 타인의 기록이나 인기 미션이 아닌 활동 아이디어라고 설명한다. API는 학급 집계 수치를 제공하지 않는다.
- UI-01: 초안 저장 뒤 학생 화면에 보이지 않는 상태, 게시 완료 상태, 학생 화면 공개를 확인했다. 내리기는 로컬 통합 테스트로 검증했고 배포 브라우저에서는 게시된 가상 안내를 유지했다. 교사 입력 실패의 수동 UI 재현은 미확인이다.
- UI-02: 교사 게시·학생 조회를 각자 인증된 세션으로 확인했고 브라우저 콘솔 오류가 없었다. 통합/Rules 테스트는 다른 교사 접근과 학생의 서버 전용 문서 직접 읽기를 차단했다. 200% 확대·VoiceOver는 미확인이다.
- 후속 P2: 여러 화면 폭, 140자 안내, 키보드 초점·오류·내리기 UI를 실기기에서 확인한다. 담당 WD-02/UI-01/UI-02. 숫자 공개 설계의 차분 추론 P1은 계속 미해결이므로 숫자 기능은 비활성으로 둔다.
- 판정: 콘텐츠/안내만의 범위에서 확인한 P0/P1 없음. 학급 수치 공개는 착수 승인 범위 밖이다.
