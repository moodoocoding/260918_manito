# 전문가 검토 기록: 월드의 구역 표지·보행 바로가기·최상단 바 제거

## 검토 정보

- 날짜: 2026-10-30. 수행: `/root`의 여섯 가상 프로파일별 역할 검토. `/root/east_flow_review`의 읽기 전용 보조 검토를 병행한다. 외부 인간 전문가 승인을 뜻하지 않는다.
- 요구사항: 사용자가 불필요하다고 지정한 동쪽/서쪽 마을 표지, 위쪽 보행 버튼, ‘우리 반 비밀친구·선생님 도움·로그인 화면’ 최상단 바를 제거한다.
- 입력 자료: 사용자 요청, `StudentClassroom.tsx`, `student-world.css`, `main.tsx`, `preview/world.tsx`, 운영 지침·여섯 프로파일, 기존 마을 확장 검토.
- 범위: 월드의 장식·중복 탐색 제거. 로그인·교사·학생 내부 기능 페이지는 유지한다. 두 배 폭의 연속 지도·이동·근접 상호작용·라우트·위치 복귀·기존 링크는 유지한다. 서버/데이터 변경 없음.

## 사용자와 설계안

- 과업: 캐릭터를 움직여 긴 마을을 탐색하고 건물 앞에서 상호작용한다. 지역 구분이 아닌 건물과 캐릭터가 핵심이다.
- 현재 문제: 사용자 보고로 지역 이름·이동 바로가기·브랜드 바가 불필요하게 화면을 차지한다.
- 구조: 예시 안내/월드 제목 → 지도(건물 이름·캐릭터) → 이동 상태·상호작용·방향 버튼. 지도 위 작은 ‘우리 반 마을’ 행도 구역 표기와 함께 제거한다.
- 실제 학생 월드에서는 최상단 바를 숨긴다. 공용기기 종료 동작은 지도 하단에 ‘활동 마치기’로 보존한다. 미리보기에는 인증/종료 동작을 추가하지 않는다. 사용자 지정에 따라 도움 버튼을 월드에 재배치하지 않고 기존 내부 페이지에서 유지한다.
- 상태: 원거리/보행/근접/준비 중/복귀 유지. 새로운 저장·오류·로딩 상태 없음. 남는 안내문은 줄바꿈을 허용한다.
- 반응형: 200% 지도 폭 유지. 360/390px에서는 표지 72px 이상·48px 높이, 이름 줄바꿈과 이미지 크기를 지도 비율에 맞춰 조정한다. 하단 주 조작은 48px 유지. 768/1280px 및 키보드 초점·이동 확인.
