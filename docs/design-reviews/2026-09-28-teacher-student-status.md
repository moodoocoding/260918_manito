# 교사 상태 확인 화면 사전 검토

## 범위와 근거

- 2026-09-28, Codex 한 에이전트가 여섯 가상 전문가 프로파일로 각각 검토했다. 실제 외부 전문가·교사·학생 참여는 없다.
- 요청: `상태 확인` 메뉴, 학생 카드의 이번 시즌 미션 완료·쪽지 발송 수, 카드 상세의 실시·미실시 미션과 최근부터 모든 대화 쪽지, `안전 확인` 메뉴 제거. 기존 안전 대응은 유지한다.
- 현황: `안전 확인` 한 화면에 도움 요청·구 방식 쪽지 검토·대화 모니터링·접속 지원이 섞여 있다. `학급 설정`은 학생의 정보 열람/정정/삭제 요청 접수 목록과 학급 전체 영구 삭제이며 시즌 설정은 아니다.

## 사전 설계

- 메뉴: 운영 요약 → 시즌 설정 → 배정 확인 → 입장 카드 → **상태 확인** → 지난 활동 → 정보 요청·삭제. 종전 안전 확인 URL은 상태 확인으로 이동시킨다.
- `학급 설정`은 실제로 보통의 학급 정보 변경을 제공하지 않으므로 `정보 요청·삭제`로 표시하고, 학생의 정보 요청은 접수 내역 확인일 뿐 실제 정정·삭제 완료가 아니며 학급 삭제는 별도 위험 작업이라는 안내를 화면 첫머리에 둔다.
- 상태 확인: 진행/일시정지/공개 대기 시즌 제목과 비공개 안내 → 도움 요청·쪽지 관리 바로가기 → 학생 카드 그리드(명부순, 완료 미션 수/선택 미션 수, 실제 발송 쪽지 수; 순위·비교 색상 없음) → 카드 선택 시 한 학생 상세(완료/아직 하지 않은/쉬기 미션, 해당 학생이 보내거나 받은 시즌 쪽지 전체를 최신순, 수신·발신과 상대를 교사에게만 표시) → 도움 요청·쪽지 관리·접속 지원.
- 데이터: 승인된 담당 교사만 호출하는 요약·상세 함수를 분리한다. 요약에는 원문을 넣지 않는다. 상세 민감 열람은 학급 감사 기록을 남긴다. 미션은 시즌에 고정된 계획과 개인 상태를 합쳐 미기록 항목을 `아직 하지 않음`으로 본다. 과거 시즌은 저장된 개인 미션 문서로 읽는다. 쪽지는 학생 사본의 발신/수신 쌍을 읽어 해당 학생에게 직접 이어진 기록만 반환한다. 완료와 발송 수는 학생 평가·순위가 아니라 지원용 기록임을 명시한다.
- 상태: 시즌 없음, 학생 없음, 데이터 로딩/오류/재시도, 카드 선택/닫기, 상세 새로고침, 쪽지 없음. 학생 상세는 화면 이탈·탭 숨김에 가린다. 320~390px 한 열, 768px 두 열, 1280px 세 열 이내, 긴 이름·200자 문장은 줄바꿈한다.

| ID·심각도 | 문제 → 근거 → 영향 | 수정안 → 확인 방법 |

- 사전 결론: 여섯 관점의 설계 통과, 미해결 P0/P1 없음. P2/P3 없음. 구현 후 실제 브라우저·권한·감사·상태를 다시 판정한다.

시각 검증 중 40명 카드 뒤에 상세를 놓으면 선택 뒤 기록이 화면에서 멀어지는 P1을 발견했다. 상세를 카드 목록 앞에 열고 즉시 그 위치로 이동하도록 바꾼다. 80개 미션 뒤에 쪽지가 묻히는 문제도 예상되어 상세 안에 `미션`/`쪽지` 두 선택 버튼을 둔다. 여섯 관점 모두 과업 발견성과 비밀 열람 통제에 유리하다고 재판정하며, 선택 상태·초점·긴 콘텐츠를 구현 후 확인한다.

## 구현 후 검토

- 코드: `getTeacherStudentStatus`는 담당 교사의 시즌 참가자만 집계하며 원문을 반환하지 않는다. `getTeacherStudentDetail`은 해당 시즌 참가자 확인 뒤 본인 사본과 원문을 대조하고 민감 열람을 감사한다. 상태 화면에서 카드 선택 시에만 상세를 조회하고 5분·탭 숨김·화면 이탈에 상세를 가린다. 종전 안전 처리 기능은 상태 확인에 남겼다.
- 자동 검증: 함수 단위 12건, 가상 두 시즌·40명 통합 3건, Firestore Rules 13건, TypeScript/Vite 빌드 통과. 통합 시험에는 타 교사·학생·비참가자 조회 거절, 1명/40명 집계, 완료/미실시, 송·수신 원문, 감사 인사와 감사 기록을 포함한다.
- 실제 브라우저의 로컬 **가상 데이터 시각 검증**: 40개 카드, 긴 가상 이름, 80개 미션, 50건의 200자 수준 쪽지를 같은 컴포넌트로 표시했다. 320·360·390·768·1280px에서 문서 가로 넘침 0, 모바일 1열·태블릿 2열·데스크톱 3열을 확인했다. 선택 카드 상세가 목록 앞에 바로 나타나도록 수정했고 미션/쪽지 전환을 추가했다. Enter로 카드 열기·쪽지 선택·닫기 후 카드 초점 복귀, `aria-expanded`·`aria-pressed`, 브라우저 오류 0건을 확인했다. 임시 시각 검증 페이지는 저장소에서 제거했다.
