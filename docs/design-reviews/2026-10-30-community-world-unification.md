# 전문가 검토 기록: 게시판·자리바꾸기 공통 월드 전환

## 검토 정보

- 날짜: 2026-10-30. 대상: `StudentCommunity.tsx`, `StudentBalanceGame.tsx`, 기능 전용 CSS.
- 요청: 사용자가 고정한 ‘오늘 할 일’ 도트 교실 기준을 모든 학생 기능에 통일한다. 원 채팅의 명시적 채팅 간 안내 지시를 직접 확인했다.
- 수행: 이 채팅의 Codex 한 에이전트가 가상 프로파일 6개를 각각 적용했다. 외부 전문가 참여는 없다.
- 자료: AGENTS.md, 전문가 운영 지침과 6개 프로파일, `docs/world-design-system.md`, `docs/design-references/world-interior-approved.png`, 공통 `WorldPage.tsx`/CSS, 기존 게시판·자리바꾸기 코드, 기존 자리바꾸기 검토.
- 범위 밖: 공통 원본과 App/월드 preview 통합은 부모 채팅 담당. 함수·API·질문·권한·AI 매칭 정책은 변경하지 않는다.

## 사용자와 설계안

- 학생은 게시판에서 교사 안내와 배려 아이디어를 읽고 자리바꾸기에 진입한다. 자리바꾸기는 한 질문씩 선택 → 전체 확인 → 제출 → 대기/실패/본인 결과 순서다.
- 현재 문제(코드 관찰): 전용 CSS가 둥근 흰 카드와 픽셀 보정 규칙을 연달아 정의한다. 공통 재질·프레임과 연결되지 않고, 완료자 목록이 선택 입력보다 먼저 커져 모바일 주행동을 밀 수 있다.
- 게시판 구성: 공통 나무 헤더(마을 복귀/제목/활동 마치기) → 학급 문맥 → 자리바꾸기 진입 종이 → 교사 안내 → 배려 아이디어. 모든 기능을 한 페이지에 나열하지 않는다.
- 자리바꾸기 구성: 같은 공통 헤더 → 게시판 복귀/짧은 안내 → 내 현재 질문 또는 확인·저장·결과 종이 → 완료 요약/완료자 목록 → 선택 공개 범위.
- 부모에 `onBack`, `onExit`, `classLabel` 연결을 요청한다. 게임은 게시판 복귀를 `onBack`, 마을 복귀를 `onVillageBack`으로 구분하고 같은 종료 callback을 받는다.
- 주요 상태: 기존 로딩·오류·재시도·빈 완료 목록·선택·확인·저장 중·대기·매칭 실패·본인 결과를 유지한다. 저장 중 이탈 버튼을 비활성화하고, 미제출 선택이 있을 때 이탈하면 공통 `ConfirmDialog`로 선택 소실을 알린다. 확인창의 취소/초점 복귀를 공유한다.
- 반응형: 공통 1120px 프레임/860px 내부 폼, 768px 이하 한 열. 본문 16px, 큰 라디오 라벨·48px 이상 버튼. 긴 이름·문구는 줄바꿈, 완료자 40명은 입력 아래에서 늘어난다.
- 키보드: 실제 fieldset/legend/radio/label 유지. 진입/질문 전환의 제목 초점, 종료 뒤 진입 버튼 초점 복귀. 선택 상태는 실제 radio와 텍스트로 구분한다.
