# 전문가 검토 기록: 학생 우편함 메신저형 대화창 및 '+' 추천 문구 개편

## 검토 정보

- **날짜 / 대상 설계 버전**: 2026-09-30 / v3.1 (우편함 인터랙션 혁신)
- **요청과 변경 범위**:
  - 사용자 보고 문제 1: 불필요한 중간 요약 카드([이미지2] `나를 맡은 친구와 나` / `이 친구에게 쪽지 쓰기`)로 인한 시각 차단 및 불필요한 조작 단계.
  - 사용자 보고 문제 2: 대화 목록과 쪽지 쓰기 폼의 물리적 분리로 인한 메신저 감성 훼손.
  - 사용자 요구사항: 카카오톡 등 일반 메신저 대화창처럼 대화창 바로 밑에 입력창이 일체형으로 붙고, '+' 더하기 버튼을 눌러 이모티콘 서랍처럼 완성된 추천 문구를 선택할 수 있는 UX.
- **수행 주체·방식**: 6인 전문가 프로파일(`WD-01`, `WD-02`, `UX-01`, `UX-02`, `UI-01`, `UI-02`) 역할 기반 설계 검토.
- **입력 자료**: `web/src/StudentMail.tsx`, `web/src/style.css`, 사용자 제공 캡처 이미지 2건.
- **검토 단계**: 사전 설계 검토.

## 사용자와 설계안

- **대상 사용자**: 초등학교 1~6학년 학생 (모바일 스마트폰 및 태블릿/PC 환경).
- **핵심 과업**:
  1. 배정된 비밀친구에게 응원 쪽지 보내기 (`내가 맡은 친구`).
  2. 나를 챙겨주는 비밀친구의 쪽지에 익명으로 답장하기 (`나를 맡은 친구`).
  3. 글쓰기가 서툰 학생도 '+' 버튼을 눌러 준비된 따뜻한 문구를 1초 만에 선택하여 전송.
- **개편 설계안**:
  1. `[이미지2]` (`.conversation-heading` 및 `.student-compose-jump`) **완전 제거**: 상단 세그먼트 탭(`내가 맡은 친구` / `나를 맡은 친구`)에서 관계를 명확히 고르므로 중복된 헤더 카드 제거.
  2. **일체형 메신저 룸(`messenger-room`) 레이아웃**: 대화창(`conversation-messages`)과 하단 입력바(`chat-input-bar`)가 하나로 결합된 캔버스 구조.
  3. **`+` 추천 문구 트레이 (서랍형 UI)**:
     - 입력바 좌측에 카카오톡 스타일의 원형 `+` 버튼 배치.
     - `+` 클릭 시 입력창 바로 위에 귀여운 칩 형태의 추천 문구 목록이 펼쳐짐.
     - 칩을 클릭하면 입력창에 문구가 즉시 세팅되어 바로 전송하거나 수정 가능.
  4. **자연스러운 텍스트 입력 및 엔터키 전송**:
     - 기존의 `[준비된 문구 / 직접 쓰기]` 모드 선택 탭 강제 제거.
     - 입력창에 바로 타이핑 가능하며, `Enter` 키로 즉시 전송 (모바일 키보드에서도 자연스러운 전송).

## 발견 사항과 조치

1. **P1: 대화창 자동 스크롤**: 새 메시지가 오거나 보냈을 때 대화창의 최하단으로 부드럽게 스크롤되어야 최신 메시지가 바로 보임 ➔ `useEffect`와 `scrollIntoView` 적용.
2. **P2: 일일 전송 제한(10건) 안내**: 기존의 큼직한 뱃지 대신 입력창 상단/우측에 심플한 메타 카운터(`오늘 1/10건`)로 표시하여 화면을 어지럽히지 않음.
3. **P2: 쪽지 전송 불가 상태 처리**: 수업일이 아니거나 일일 한도 초과 시, 입력바 자리에 부드러운 안내 배너(`chat-disabled-banner`)를 렌더링.

**착수 판정**: 6개 관점 모두 통과, 미해결 P0/P1 없음. 구현 착수 승인.

## 구현 후 실제 검증

- **빌드 및 단위 테스트**: TypeScript 컴파일 및 Vite 프로덕션 빌드 성공, 함수 12건 통과, QR 1건 통과.
- **불필요한 헤더 카드 제거 확인**: `.conversation-heading`([이미지2]) 및 중복 점프 버튼이 화면에서 완전히 제거됨.
- **일체형 메신저 룸(`messenger-room`) 및 `+` 추천 문구 트레이 동작 확인**:
  - 대화 말풍선 영역 하단에 `+` 버튼, 텍스트 인풋, 전송 버튼이 결합된 입력바 배치 완료.
  - `+` 버튼 클릭 시 카카오톡 이모티콘 창처럼 추천 문구 칩 그리드가 열리며, 칩 선택 시 텍스트창에 즉시 반영.
  - 직접 입력 및 `Enter` 키 전송 지원.
- **6개 관점 사후 판정**:
  - `WD-01`: 통과 (불필요한 중간 카드 제거로 대화 캔버스가 깔끔하게 정돈됨)
  - `WD-02`: 통과 (모바일 및 데스크톱에서 입력바가 100% 폭으로 균형 있게 배치됨)
  - `UX-01`: 통과 (5단계 작성 폼을 메신저 2단계 입력으로 압축)
  - `UX-02`: 통과 (카카오톡 메신저 친화적 멘탈 모델로 인지 부하 제로화)
  - `UI-01`: 통과 (`+` 버튼 토글, 추천 문구 선택, 엔터키 전송 인터랙션 정상)
  - `UI-02`: 통과 (ARIA 라벨 및 키보드 초점, 모바일 터치 영역 42px 이상 확보)
