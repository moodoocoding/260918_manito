# 전문가 검토 기록: 교사 운영 요약·학생 카드 간격

## 검토 정보

- 날짜 / 대상: 2026-09-27, `main`의 현행 교사 화면
- 요청과 범위: 사용자 제공 화면에서 운영 요약의 다음 행동 버튼과 학생 카드 화면의 학급 코드 상자 위 여백 수정. 기능·데이터·문구·메뉴 구조는 변경하지 않는다.
- 수행 주체·방식: Codex 한 에이전트가 여섯 가상 전문가 프로파일을 각각 적용한 역할 기반 검토. 외부 전문가의 참여나 승인이 아니다.
- 입력 자료: 사용자 제공 스크린샷 2장, `web/src/TeacherRounds.tsx`, `web/src/main.tsx`, `web/src/style.css`, `docs/design-revision-plan.md`의 간격 규칙, `docs/experts/`의 운영 지침·프로파일.
- 단계: 아래 사전 설계 검토를 코드 변경 전에 기록. 구현 후 검증은 하단에 별도 기록한다.

## 사용자와 설계안

- 사용자·과업: 교사는 운영 요약에서 도움·쪽지 확인 뒤 새 회차로 이동하고, 학생·입장 카드 페이지에서 학급 코드를 확인한 뒤 학생을 등록·관리한다.
- 관찰된 문제: 첫 화면에서 확인 카드 아래에 다음 행동 버튼이 닿아 보인다. 두 번째 화면에서 페이지 설명과 학급 코드 배경 상자가 붙어 보인다. 현재 CSS에는 두 경계의 수직 간격 지정이 없다. 사용자 스크린샷은 실제 배포 화면의 일부이며, 폭·확대율은 확인하지 못했다.
- 페이지·섹션: 학급 맥락 → 운영 요약(현재 회차, 먼저 확인, 다음 행동) 또는 학생·입장 카드(제목·설명, 학급 코드, 등록, 카드 관리). 메뉴와 이동 경로는 유지한다.
- 배치: 운영 요약의 확인 카드와 다음 행동 버튼 사이에 24px, 학생·입장 카드의 제목·설명 블록과 학급 코드 상자 사이에 24px을 둔다. 제목과 설명의 기존 8px 간격, 카드 안쪽 여백과 카드 간 16px은 유지한다. 기존 디자인 계획의 4·8·12·16·24·32·48px 단계를 따른다.
- 상태·반응형: 회차 없음/진행 중, 학생 없음/목록 있음, 오류·로딩 상태에서도 각 간격이 유지돼야 한다. 1280·768·390·360px에서 카드 열 수와 줄바꿈을 확인한다. 긴 학급명과 최대 학생 수로 내용이 늘어나도 고정 높이를 사용하지 않는다. 버튼의 이름·초점·키보드 이동은 기존 의미를 유지한다.

- 의견 차이와 선택 이유: 전체 `.page-header`에 공통 여백을 주면 다른 교사 페이지의 기존 문단 여백과 합쳐져 밀도가 달라진다. 스크린샷에 확인된 두 경계에 적용하고, 검증 중 같은 결함이 발견되면 범위를 갱신한다.
- 수정 후 6개 관점 재판정: 위의 구체적 배치안을 여섯 관점에서 다시 확인했으며 모두 통과. 현재 범위의 P0·P1은 없고 P2 두 건은 이번 구현·브라우저 확인으로 해결한다.
- 착수 판정: 2026-09-27, 여섯 관점 통과. 코드 수정 가능.
- 남긴 P2·P3: 없음. 새 결함은 구현 후 검증에서 기록한다.

- 로컬 Vite의 로그인 전 교사 페이지는 본문과 로그인 버튼이 표시되고 Vite 오류 오버레이가 없었다. 인증 후 검증 중 콘솔에 오류는 없었고 Vite debug·React DevTools 안내만 있었다.
