# 6인 전문가 검토 기록: 학생 미션 UI 단순화 및 워크플로우 전면 개편

- **일자**: 2026-09-30
- **대상 기능**: 학생 미션 화면 드롭박스 필터 제거, 완료 미션 잠금 및 완료 표시, 불필요한 '쉬기'/'바꾸기' 제거 및 직관적 액션 통일
- **관련 파일**: `web/src/StudentRound.tsx`, `web/src/style.css`

---

## 1. 개요 및 요구사항

### 현황 및 문제점
1. **불필요한 필터 드롭다운**: 학급당 미션이 10개 내외인데 "기록 상태", "미션 종류" 드롭박스 2개가 화면 상단을 차지하여 인지 부담을 주고 목록 탐색을 방해함.
2. **완료 미션의 재선택 혼란**: 이미 완료한 미션인데도 다른 미션과 동일하게 열리고 버튼이 노출되어 다시 선택하거나 완료를 누를 수 있는 오조작 가능성이 존재함. 완료된 미션은 명확한 '완료됨' 표시와 함께 재선택을 차단(잠금)해야 함.
3. **불필요하고 혼란스러운 액션 난립**:
   - '이 미션 쉬기': 학생이 미션을 안 하면 그만인데 굳이 '쉬기' 버튼이 있어서 불필요한 분기와 고민을 만듦.
   - '이 미션 바꾸기' vs '이번에 해볼래요': 목록에서 원하는 미션을 골라 하는 것과 '바꾸기'(영구 제외)가 용어상 중복되고 심각한 혼란을 초래함.

### 사용자 과업
- 학생은 10개 미션을 한눈에 카드 목록으로 보고,
- 마음에 드는 미션을 골라 "이번에 해볼래요"로 선택하거나 바로 "✨ 해냈어요!"로 완료한다.
- 완료한 미션은 `✓ 완료됨`으로 잠겨 다시 선택할 수 없다.

## 2. 6개 전문가 관점 개별 검토

### WD-01 · 시각 구성과 브랜드
- **판단**: 승인
- **근거**: 상단의 복잡한 드롭박스 2개를 걷어내고, 미션 카드 그리드를 시원하게 배치한다. 카드는 3가지 시각 상태(완료됨: 은은한 소프트 그린/그레이 톤에 체크 뱃지, 현재 도전 중: 활성화된 보라색 테두리와 '🎯 지금 도전 중' 뱃지, 미완료: 깔끔한 기본 카드)로 위계를 명확히 분리한다.

### WD-02 · 반응형 레이아웃과 타이포그래피
- **판단**: 승인
- **근거**: 모바일 화면에서 드롭다운이 차지하던 스크롤 길이를 절약하고, 각 미션 카드가 한눈에 쏙 들어오도록 반응형 패딩과 버튼 배치를 최적화한다.

### UX-01 · 정보 구조와 과업 흐름
- **판단**: 승인
- **근거**:
  - [홈] 오늘의 미션 → 완료 또는 [미션 탭에서 다른 미션 고르기]
  - [미션 탭] 10개 미션 목록 확인 → 마음에 드는 미션 [이번에 해볼래요] 또는 [✨ 해냈어요!]
  - '쉬기'와 '바꾸기'를 완전히 제거하여 과업 경로를 일직선으로 단순화함.

### UX-02 · 인지 부담과 사용자 이해
- **판단**: 승인
- **근거**: 초등학생에게 "쉬기 vs 안 하기", "바꾸기 vs 다른 미션 선택"의 난해한 개념 구분을 강요하지 않음. 완료된 미션은 잠가서 재도전 실수나 중복 입력을 사전에 원천 차단함.

### UI-01 · 조작과 컴포넌트 상태
- **판단**: 승인
- **근거**:
  - 완료된 미션: `is-done` 클래스 부여, 버튼 영역에 `✓ 완료됨` 비활성 뱃지 고정.
  - 현재 선택된 미션: `is-focused` 클래스, `✨ 해냈어요!` 버튼만 노출.
  - 대기 미션: `이번에 해볼래요`와 `해냈어요` 2가지 명확한 액션만 제공.

### UI-02 · 접근성과 화면 품질
- **판단**: 승인
- **근거**: 불필요한 컨트롤이 줄어 키보드 Tab 탐색 단계가 60% 이상 단축되며, 스크린리더 사용자에게도 미션 목록과 상태가 훨씬 명료하게 전달됨.

## 4. 구현 후 6인 전문가 재검토 및 검증 결과

### WD-01 · 시각 구성과 브랜드
- **확인 결과**: 통과
- **근거**: 상단 드롭박스를 제거하여 화면이 훨씬 넓고 시원해짐. 완료된 미션은 은은한 그린 배경(`.is-done`)과 `✓ 완료됨` 뱃지로 정돈되어 남아있는 미션과의 시각적 구분이 명확함.

### WD-02 · 반응형 레이아웃과 타이포그래피
- **확인 결과**: 통과
- **근거**: 모바일과 데스크톱 모두에서 미션 카드 리스트가 여백 없이 자연스럽게 채워지며, 버튼들이 우측에 안정적으로 배치됨.

### UX-01 · 정보 구조와 과업 흐름
- **확인 결과**: 통과
- **근거**:
  - '기록 상태/미션 종류' 드롭박스 완전 제거로 10개 미션을 한눈에 스크롤 탐색 가능.
  - '이 미션 쉬기'와 '이 미션 바꾸기'를 제거하고 오직 `[이번에 해볼래요]`와 `[✨ 해냈어요!]`로 단일화하여 초등학생도 즉시 이해 가능한 워크플로우 완성.

### UX-02 · 인지 부담과 사용자 이해
- **확인 결과**: 통과
- **근거**: 완료된 미션은 `✓ 완료됨`으로 잠겨 다시 선택하거나 클릭할 수 없게 되어 재선택 혼란을 원천 방지함.

### UI-01 · 조작과 컴포넌트 상태
- **확인 결과**: 통과
- **근거**:
  - 미션 카드에서 즉시 '이번에 해볼래요' 클릭 시 `setStudentMissionFocus`가 호출되어 홈 화면의 오늘의 미션과 동기화됨.
  - '✨ 해냈어요!' 클릭 시 `setMissionStatus(done)`가 호출되고 즉시 완료 카드로 상태 전환됨.

### UI-02 · 접근성과 화면 품질
- **확인 결과**: 통과
- **근거**: Vite 프로덕션 빌드 및 12개 함수 단위 테스트 100% 통과.
