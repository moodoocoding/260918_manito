## 사용자와 설계안

- 대상 사용자·이용 환경·핵심 과업:
  - **학생(초등 1~6학년, 모바일·태블릿·공용 PC):** 학급/개인 카드 코드로 입장 → 홈에서 오늘의 핵심 미션 확인·완료(`해냈어요`) → 미션 탐색·선택 → 우편함에서 두 관계별 익명 쪽지 송수신 → 우리 반 배려 아이디어 확인 → 도움 요청 및 활동 마치기
  - **교사(데스크톱·태블릿·모바일):** Google 로그인 → 학급 선택/생성 → 입장 카드 발급·인쇄 → 시즌 5단계 설정 및 매칭 시작 → 운영 요약에서 도움 요청·쪽지 모니터링 우선 확인 → 상태 확인에서 학생별 기록·안전 처리 → 정체 공개 승인 및 보관
- 현재 문제와 재현 조건 (코드·실제 캡처 관찰 및 사용자 보고):
  1. **영역 구분 붕괴 (관찰·사용자 보고):** 배경(`#fff8ed`) 위에 상단 바(`.topbar`), 학생 메뉴(`.student-nav`), 페이지 제목(`.student-page-title`), 교사 학급 제목(`.teacher-context`)이 배경 컨테이너나 경계선 없이 그대로 떠 있고, 카드 테두리(`#f3e5d8`)와 서브카드(`#fffaf5`)의 명도 대비가 극도로 낮아 화면 전체가 하나의 미색 종이처럼 뭉개져 보임.
  2. **핵심 포인트(Focal Point) 실종 (관찰·사용자 보고):** 학생 홈에서 시즌 상태, 내 미션 요약, 이번에 해볼 미션, 안내 문구가 단일 흰 패널(`.student-home-primary`) 안에 평면 텍스트로만 나열되어 가장 중요한 ‘이번에 해볼 미션’과 ‘해냈어요’가 눈에 띄지 않음. 교사 운영 요약에서도 진행 중인 시즌 정보와 참가 인원·일정이 단순 `<p>`와 `<h3>` 줄글로 나열됨.
  3. **모든 버튼의 시각 동질화 (관찰):** 주 실행 버튼(`#b94440`)과 보조/탭/필터/이동 버튼(`.outline`: `#8d302b` 테두리·글자)이 모두 붉은 벽돌색 계열을 사용해, 탭 전환(`내가 맡은 친구 / 나를 맡은 친구`, `준비된 문구 / 직접 쓰기`, `학생 기록 / 도움 요청`)과 실제 제출 버튼이 시각적으로 경쟁함.
  4. **모바일 첫 화면(390×844px) 핵심 행동 잘림 및 배지 중복 (실제 캡처 `student-login-390.png` 확인):** 상단 메뉴에 `학생 입장` 버튼이 있는데 바로 아래 또 `학생 입장` 분홍 배지가 중복되고, 자간이 뭉개진(`letter-spacing: -0.06em`) 거대한 제목과 단독 행을 차지하는 `코드 보기` 버튼(높이 44px) 때문에 정작 가장 중요한 `입장하기` 버튼이 390×844px 화면 아래로 잘려 보이지 않음.
  5. **교사 상태 확인의 3중 제목 중복 및 고립 버튼 (관찰):** 상태 확인 화면에서 `<h2>상태 확인</h2>` → `<h3 class="status-section-title">학생별 미션·쪽지 기록</h3>` → `<h3 id="teacher-student-status-heading">학생별 상태</h3>`가 연속으로 3번 겹쳐 나오고, 학생 홈 하단에는 `지난 활동 보기`와 `새 소식 확인` 버튼이 소속 영역 없이 바닥에 떠 있음.
- 페이지·섹션 구성과 이동 경로 (4계층 표면 구조):
  - **Layer 0 (App Canvas `#f4eee4`):** 카드와 크롬이 선명히 떠오르는 따뜻한 오트밀 캔버스
  - **Layer 1 (Structural Chrome):** 상단 고정형 헤더 바(흰색 표면 + 하단 경계선 + 서비스 전환 세그먼트 트랙), 학생 4탭 내비게이션 트랙 바, 교사 학급 문맥 헤더 카드(`.teacher-context`) 및 좌측 사이드바
  - **Layer 2 (Section Panel):** 뚜렷한 테두리(`#dfd3c3`)와 그림자를 가진 흰색 섹션 카드 + 내부 서브 그리드(3열 요약 타일, 우편함 대화방 캔버스 `#f6f1e8`, 교사 일정 칩 그리드)
  - **Layer 3 (Focal Point Spotlight):**
    - 입장 화면: 우측(모바일은 바로 아래) 로그인 카드에 시선이 바로 모이도록 상단 Hero를 정돈하고 주 버튼을 첫 화면 안에 배치
    - 학생 홈: 시즌 요약 헤더 및 3열 숫자 타일 바로 아래에 **‘이번에 해볼 미션 스포트라이트 박스’**(코랄 강조 테두리 `2px solid #d96b43`, 상단 배지, 큰 미션 문구, 전체 폭 주 행동 버튼)를 독립된 시각 초점으로 배치
    - 교사 운영 요약: 상단 **활성 시즌 배너** + 대기 건수에 따라 강조 상태가 바뀌는 **우선 확인 업무 카드 2개(도움 요청 / 쪽지 모니터링)** + 하단 **접속·일정 2열 요약 박스**
- 반응형·긴 텍스트·최대 항목·키보드 설계:
  - 320·360·390·768·1280px 전 구간 가로 넘침 0 유지, 390×844px에서 입장 화면 `입장하기`/`Google로 로그인` 및 학생 홈 `해냈어요` 주 행동이 첫 화면(Fold) 안에 완전히 노출되도록 설계
  - 한글 제목 자간을 `-0.02em`으로 교정해 글자 뭉침 해소

## 구현 후 실제 검증

- 검증 환경·방법: 로컬 프로덕션 빌드(`web/dist`)를 실제 Headless Chromium(Google Chrome 134+)에서 `320×568`, `360×800`, `390×844`, `768×1024`, `1280×800` 및 `320×700`(글자 크기 200% 확대 `font-size: 32px`) 뷰포트로 렌더링하고, 실제 입장 화면(`/student`, `/teacher`)과 합성 데이터가 주입된 학생 화면(`홈`, `미션`, `우편함`, `우리 반`), 교사 화면(`운영 요약`, `상태 확인`)의 DOM 기하 수치 및 스크린샷(`docs/design-reviews/assets/*.png`)을 육안 검수했다.
- 뷰포트별 측정 결과:
  - **가로 넘침(`scrollWidth - innerWidth`):** `320`, `360`, `390`, `768`, `1280px` 및 `320px@200%` 전 시나리오 41건 모두 `overflowX = 0px`.
  - **모바일 첫 화면(390×844px) 핵심 행동 노출(Above-the-Fold):**
    - 학생 입장(`/student`): `입장하기` 주 실행 버튼 하단 `Y = 710px` (`<= 844px`, 화면 하단 여유 134px 확보; 개편 전에는 화면 밖으로 완전히 잘림).
    - 교사 입장(`/teacher`): `Google로 로그인` 주 실행 버튼 하단 `Y = 624px` (`<= 844px`).
    - 학생 홈(`/student` 인증 화면): 시즌 배너 + 3열 숫자 타일(`해봤어요 3 / 골라볼 미션 6 / 쉬었어요 1`) + `이번에 해볼 미션` 스포트라이트 카드 안의 `해냈어요` 주 실행 버튼 하단 `Y = 764px` (`<= 844px`, 첫 화면 안에 완전 노출).

- 6개 관점 사후 판정:
  - **WD-01 (시각 구성):** 오트밀 캔버스(`#f3ede2`), 흰색 상단 바·패널(`#ffffff`), 서브 트랙(`#efe8dc` / `#f7f2e9`), 코랄 스포트라이트 카드(`#d96b43` 2px 테두리)의 4계층 표면 대비와 컨트롤 색상 분리가 캡처 이미지에서 명확히 확인됨 (통과).
