## 1. 사전 요구사항 및 문제 진단

### 문제점 1: 기존 학생 코드가 여전히 12자리로 길게 표시됨
- **원인**: 기존에 등록된 학생들의 카드가 12자리 구 규격(`XXXX-YYYYYYYY`)으로 발급되어 `studentCredentials`에 암호화 보관되어 있음.
- `rotateStudentCredential`은 1명씩만 재발급 가능하여, 20~30명 학급의 교사가 4자리 코드로 교체하기 불가능함.
- **해결안**: 백엔드에 선택/전체 학생 대상 `reissueStudentCards` 함수를 제공하고, 교사 화면의 입장 카드 관리 상단에 **`[4자리 코드로 전체 재발급]`** 및 **`[선택한 카드 4자리로 재발급]`** 원클릭 액션을 제공.

### 문제점 2: 입장 카드 인쇄 시 정상 출력되지 않음
- **원인**:
  1. `@media print`에서 교사 관리 화면(`.content`)이 숨겨지지 않아, 인쇄 대화상자에 교사 페이지 전체(학급 헤더, 메뉴, 학생 리스트 테이블)가 첫 몇 장에 걸쳐 출력되고 카드가 겹치거나 잘림.
  2. Safari/Chrome에서 `window.print()` 호출 직후 `onafterprint`가 조기 발화하여 인쇄 미리보기가 뜨기도 전에 `setPrintSheet(null)`이 실행되어 빈 페이지(백지)가 인쇄됨.
  3. 50ms라는 너무 짧은 대기 시간으로 인해 QR 이미지가 렌더링되기 전에 인쇄 프로세스가 시작됨.
- **해결안**:
  1. `@media print` 시 오직 `.print-only`만 노출되고 `.app-shell`, `.content`, `.topbar` 등 모든 웹 화면을 `display: none !important`로 철저히 격리.
  2. 인쇄 시 `document.body.classList.add("is-printing-cards")`를 부여하고, 인쇄 전용 모달 창(또는 명시적인 인쇄 완료 닫기 제어)을 통해 조기 언마운트 버그를 완벽 차단.
  3. `@page { size: A4 portrait; margin: 12mm 15mm; }` 및 `page-break-after: always`로 각 카드가 깔끔하게 한 장씩 출력되도록 보장.

## 2. 6개 관점 개별 검토 및 판단

### WD-01 · 시각 구성과 브랜드
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 인쇄되는 카드는 초등학생이 소지하기 좋은 따뜻하고 명확한 카드 디자인을 유지하며, 학교 프린터(흑백/컬러)에서 선명하게 나오도록 고대비 테두리와 폰트 크기(이름 24pt, 코드 20pt)를 적용함.
  - 교사 화면 툴바에 `4자리 코드로 일괄 재발급` 버튼을 보조 outline 스타일로 단정하게 배치.

### WD-02 · 반응형 레이아웃과 타이포그래피
- **판단**: 통과 (개선안 반영)
- **근거**:
  - A4 용지 규격에 맞춰 카드 높이와 여백을 최적화하여 1장에 1장(또는 반으로 접을 수 있는 형태)이 깔끔하게 인쇄되도록 CSS 페이지 브레이크(`break-inside: avoid; break-after: page;`)를 엄격 적용함.

### UX-01 · 정보 구조와 과업 흐름
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 교사가 12자리 구 코드를 쓰는 학생들을 확인하고 "전체 4자리 코드로 재발급" 버튼 하나로 즉시 전환할 수 있어 작업 시간을 1초로 단축.
  - 인쇄 시 미리보기 화면이 닫히지 않고 교사가 "인쇄 다이얼로그 확인 후 [닫기]"를 누를 때까지 유지되어 브라우저 조기 닫힘 버그를 방지함.

### UX-02 · 인지 부담과 사용자 이해
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 12자리 코드를 학생에게 안내해야 했던 교사의 부담을 완전히 없애고, 4자리(예: `7K9X`)의 간결한 코드만 발급됨을 명확히 안내.
  - 재발급 시 기존 카드는 즉시 무효화된다는 점을 모달 다이얼로그로 명확히 고지하여 보안 위험 방지.

### UI-01 · 조작과 컴포넌트 상태
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 일괄 재발급 진행 중 `busy` 상태 및 프로그레스 피드백 표시.
  - 인쇄 실행 시 화면 상단에 인쇄 상태 안내 및 수동 [인쇄 닫기] 버튼을 제공하여 언제든 안전하게 복귀 가능.

### UI-02 · 접근성과 화면 품질
- **판단**: 통과 (개선안 반영)
- **근거**:
  - 인쇄 시 `@media print`의 백그라운드 컬러 무시 및 검정 텍스트/선명한 테두리(`border: 2px solid #000000`) 적용.
  - 스크린리더용 알림 및 키보드 조작성 유지.

## 4. 구현 후 6개 관점 재검토 결과

1. **WD-01 (시각 구성과 브랜드)**: 통과. 인쇄 시 오직 A4 규격에 정밀하게 맞춰진 입장 카드(`.printed-card`)만 선명한 테두리와 적정 폰트로 렌더링되며, 화면 미리보기 오버레이 및 상단 컨트롤 바가 단정하고 완성도 높은 시각 피드백을 제공함.
2. **WD-02 (반응형 레이아웃과 타이포그래피)**: 통과. `@page { size: A4 portrait; margin: 12mm 15mm; }`와 `break-inside: avoid; break-after: page;`가 적용되어 어떤 프린터 드라이버에서도 페이지 잘림 없이 1장씩 깔끔하게 분할 인쇄됨.
3. **UX-01 (정보 구조와 과업 흐름)**: 통과. 이전의 긴 12자리 구 코드를 사용하는 학생을 배너로 자동 감지하고, "4자리 코드로 전체 재발급" 버튼 클릭 한 번으로 모든 학생의 코드를 4자리 새 코드로 교체하는 직관적인 워크플로우 확립.
4. **UX-02 (인지 부담과 사용자 이해)**: 통과. 학생들에게 안내하기 난감했던 12자리 난수 코드를 4자리(예: `7K9X`)로 전면 교체하여 초등학생의 타이핑 부담을 최소화함. 인쇄창 조기 닫힘 버그가 해결되어 교사가 당황하지 않고 화면에서 직접 인쇄 미리보기를 확인하고 제어할 수 있음.
5. **UI-01 (조작과 컴포넌트 상태)**: 통과. 일괄 재발급 확인 다이얼로그(`ConfirmDialog`), 인쇄 제어 바(`[다시 인쇄하기]`, `[인쇄 완료 / 닫기]`), 실시간 코드 갱신 피드백이 완벽히 작동함.
6. **UI-02 (접근성과 화면 품질)**: 통과. 인쇄 모달 내 QR 이미지 로딩 완료 대기 및 흑백 고대비 인쇄 지원, TypeScript 빌드 0 error 통과.
