# 전문가 검토 기록: 학생 홈 화면의 불필요한 부가 안내 문구 제거

## 검토 정보

- **날짜 / 대상 설계 버전 또는 커밋**: 2026-09-30 / v3.4 (학생 홈 미니멀리즘 및 시각적 노이즈 제거)
- **요청과 변경 범위**:
  - 사용자 요청: 학생 홈 화면의 불필요한 안내 문구인 "원하는 순서로 참여해요"와 "진행 중에는 친구의 이름을 볼 수 없어요. 쪽지는 서버가 배정된 친구에게 전해요." 제거 요청.
  - 변경 범위: `web/src/StudentRound.tsx` 내 미션 현황 서브텍스트 제거 및 시즌 카드 하단 서버 배정 안내 문구 제거.
- **수행 주체·방식**: 6인 전문가 프로파일(`WD-01`, `WD-02`, `UX-01`, `UX-02`, `UI-01`, `UI-02`) 역할 기반 설계 검토.
- **입력 자료**: `web/src/StudentRound.tsx`.
- **검토 단계**: 사전 설계 검토.

---

## 사용자와 설계안

- **대상 사용자**: 초등학교 1~6학년 학생.
- **핵심 과업**:
  - 홈 화면에서 직관적으로 오늘의 미션과 내 미션 현황을 확인하고 활동에 몰입.
- **개편 설계안**:
  1. `summary-head` 내의 불필요한 잔여 텍스트 `<span>원하는 순서로 참여해요</span>` 삭제 ➔ 헤더를 깔끔하게 `<strong>내 미션 현황</strong>`으로만 구성.
  2. 마니또 규칙상 당연한 사실을 장황하게 설명하던 하단 안내 문구 `"진행 중에는 친구의 이름을 볼 수 없어요. 쪽지는 서버가 배정된 친구에게 전해요."` 완전 삭제. 공개 완료 시의 안내(`{revealed && <p className="field-help">선생님이 친구를 공개했어요. 아래에서 내 관계를 확인할 수 있어요.</p>}`)만 유지.

## 6개 관점의 사전 판단

| 프로파일 | 검토 내용과 근거 | 판정 |
|---|---|---|
| **WD-01 · 시각 구성과 브랜드** | 불필요한 텍스트 줄바꿈과 시스템 중심적 문구가 사라져, 카드 내부가 여백을 확보하고 핵심 콘텐츠인 '미션 타일'과 '오늘의 미션'에 시선이 집중됨. | **통과** |
| **WD-02 · 반응형 레이아웃과 타이포그래피** | 좁은 모바일 화면(390px)에서 불필요한 2~3줄 텍스트가 줄어들어 스크롤 길이가 단축되고 수직 리듬이 쾌적해짐. | **통과** |
| **UX-01 · 정보 구조와 과업 흐름** | 학생들이 이미 인지하고 있는 당연한 규칙("서버가 쪽지를 전해요" 등)을 반복 주입하지 않아 정보 과밀이 해소됨. | **통과** |
| **UX-02 · 인지 부담과 사용자 이해** | 초등학생의 멘탈 모델에 어색한 "서버가 배정된 친구에게…" 같은 기계적/개발자적 문구를 제거하여 동화적이고 자연스러운 마니또 몰입감 제공. | **통과** |
| **UI-01 · 조작과 컴포넌트 상태** | 조작 버튼이 아닌 텍스트 라벨 제거 작업이므로 기존 인터랙션 상태에 부작용 없음. | **통과** |
| **UI-02 · 접근성과 화면 품질** | 스크린리더 청취 시 불필요한 부가 안내 음성 낭비가 줄어들어 핵심 콘텐츠 탐색 속도 향상. | **통과** |

## 발견 사항과 조치

1. **P2: 공개 완료 시의 안내 처리**:
   - `revealed` 상태일 때는 친구가 공개되었다는 안내가 필요하므로, 조건부로 `revealed`일 때만 상단 안내 문구를 노출하도록 유지.

**착수 판정**: 6개 관점 모두 통과, 미해결 P0/P1 없음. 구현 착수 승인.

## 구현 후 6인 전문가 재검토 및 검증 결과

- **WD-01 / WD-02**: '내 미션 현황' 헤더가 단정해지고 불필요한 하단 장문이 제거되어 모바일 뷰포트에서 스크롤 부담이 줄어듦.
- **UX-01 / UX-02**: 학생 입장에서 "서버가 쪽지를 전해요" 같은 부자연스러운 기계적 설명이 사라져 자연스러운 마니또 감성 유지.
- **UI-01 / UI-02**: TypeScript 빌드, Vite 프로덕션 빌드, 함수 단위 테스트 12건, QR 테스트 1건 통과.
