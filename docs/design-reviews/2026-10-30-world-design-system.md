# 전문가 검토 기록: 승인된 도트 교실 시안으로 공통 디자인 통일

## 요구와 근거

- 2026-10-30 사용자가 기능별 디자인 차이를 지적하고 AGENTS·공통 코드·각 채팅 전달을 요청했다. 이어 ‘오늘 할 일’ 이미지를 직접 첨부해 해당 스타일을 명시적으로 고정했다.
- 수행: `/root`의 여섯 가상 프로파일별 검토와 `/root/teacher_mail_inbox`의 독립 읽기 검토. 인간 전문가 승인을 뜻하지 않는다.
- 입력: 사용자 첨부 시안, 메인 도트 마을, 현재 오늘 할 일/우체통/게시판·자리바꾸기, 기존 전문가 운영 지침·여섯 프로파일. 공유 아트는 별도 검토 기록을 따른다.
- 핵심: 색상만 유사하게 만드는 것으로 완료하지 않는다. 실제 도트 교실 배경·두꺼운 나무 게시판·양피지 카드·픽셀 아이콘·큰 초록 주행동을 공통으로 사용한다. 메인 외부 마을과 로그인은 기존 승인 아트를 보존한다.

## 설계·과업·상태·반응형

- 학생의 모든 기능: 공통 교실 배경 → 공통 나무 프레임 → 좌 마을 복귀/중앙 제목/우 활동 마치기 → 불투명 양피지 → 기능 내용. 기존 브랜드바/별도 중복 제목을 재도입하지 않는다.
- 기능 API/권한/입력/저장 상태는 유지하고 이탈 callback을 공통 헤더에 전달한다. 공통 디자인이 입력을 임의 삭제하거나 고정 URL로 이동하지 않는다. 제목의 `.student-page-title`·초점과 기존 오류/저장 상태를 보존한다.
- `world-design-system.css`가 색·간격·글자·프레임·버튼·필드·상태 원본이며 `WorldPage.tsx`가 재사용 헤더/프레임/종이/버튼/아이콘을 제공한다. 기능 CSS는 질문/목록/입력 배치만 담당한다.
- 최종 최대1200px, 내부 긴 폼860px. 본문은 화면에 따라16~20px, 제목24~48px, 주행동은 데스크톱64px/모바일52px 이상이다. 768px 이하 내용 카드 한 열, 640px 이하 제목 한 행/복귀·종료 다음 행. 이미지 전체를 축소하지 않고 실제 HTML 요소를 재배치한다. 화면 비례 바깥 여백과 모바일 배경 위치로 도트 풍경을 계속 드러낸다.
- 메인 로비 노랑 상호작용은 유지하고 기능 주행동은 초록, 보조는 크림, 오류/위험은 적갈색으로 구분한다. 교사는 공통 색/글자/조작 원칙을 쓰되 표와 안전 업무를 위해 장식 없는 업무 표면을 유지한다.

- 공통 `WorldPageFrame/Header/Paper/Button/PixelIcon`을 오늘 할 일·우체통·게시판/자리바꾸기·준비 중 공간에 연결했다. 기존 미션/친구 쪽지/도움/지난 활동은 공통 경계 컴포넌트로 감싸 중복 제목을 제거했다. 로그인·외부 마을은 기존 아트를 유지한다.

## 활성 마니또 카드의 CSS 우선순위 보완 · 2026-10-30

부모 Codex가 6개 가상 역할로 검토했다. 실제 외부 전문가는 참여하지 않았다. 부모 IAB5182의 실제 미션320px에서 legacy `.student-grid .panel`/모바일 `.student-app .student-grid .panel`이 공통 `.world-feature-page .panel`보다 우선해22/18px모서리가 남는 것을 관찰했다. 활성홈만별도선택자로고친상태에서도 미션/도움/쪽지/권리 안내 카드가같은문제를가질수있다.

수정안은 공통원본의 기존 panel 규칙에 `.student-app .world-feature-page .world-paper .panel` 선택자를 추가하는 것이다. 같은3px공통radius/양피지/테두리/그림자를 사용하고 새토큰을복제하지않는다. 교사/로그인/외부지도는새선택자대상이아니며과업별padding/글자/실저장/이탈/비밀유지로직은바꾸지않는다. 학생의원래round API/버튼/폼/명부접근도불변이다.

- WD-01: 실제18px곡면과승인3px표면충돌을공통원본에서해결하므로사전통과.
- WD-02: 기존콘텐츠폭/반응형열/패딩은보존하고모서리만원래공통규칙이적용되게하므로사전통과.320/390/1280실제카드확인예정.
