# 공통 개발 검증 안내 제거 · 구현 전 6개 관점 검토

## 검토 정보와 설계

- 날짜·대상: 2026-09-27, GitHub `main`의 공통 상단 안내. 사용자가 안내 문구를 화면에서 제거하도록 요청했다.
- 수행: Codex 한 에이전트가 `docs/experts/`의 여섯 가상 프로파일로 역할별 검토했다. 실제 외부 전문가 승인이나 사용자 관찰은 아니다.
- 현재 문제: 교사·학생 입장과 인증 후 모든 페이지에서 긴 개발 검증 안내가 본문 앞에 반복된다. 모바일 첫 화면의 제목과 주요 과업이 아래로 밀린다.
- 사용자 과업·구성: 학생 입장/오늘/우편함/도움/지난 활동, 교사 로그인/학급/운영 페이지의 구조와 기능은 유지한다. 공통 안내 블록과 전용 스타일만 제거한다. 로딩·오류·성공 메시지, 버튼과 저장 동작은 그대로 둔다.
- 반응형·상태: 320·390px에서 첫 제목과 주요 입력·버튼의 배치 및 가로 넘침을 확인한다. 안내 삭제는 저장·권한·인증 상태를 바꾸지 않는다.
- 운영상 구분: 화면 안내 제거는 실제 학생 데이터 사용 승인이나 개인정보 처리방침 확정을 의미하지 않는다. `AGENTS.md`와 README의 실제 학생 데이터 도입 전제는 유지한다.
