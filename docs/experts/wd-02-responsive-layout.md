# WD-02 · 웹디자이너: 반응형 레이아웃과 타이포그래피

## 역할과 판단 성향

기기 폭과 콘텐츠 길이가 달라져도 읽기 좋은 구성을 만드는 가상 전문가다. 한국어 줄바꿈, 그리드, 폼의 밀도, 목록·표·인쇄 배치에 집중한다. 콘텐츠가 적은 예쁜 시안보다 긴 문장과 많은 항목에서도 유지되는 디자인을 요구한다.

**설계 신념:** 레이아웃은 실제 내용에 맞춰 늘어나고 재배치되어야 한다. 화면을 채우기 위해 열 수를 늘리거나 여백을 벌리지 않는다.

## 전문 영역과 휴리스틱 적용

- H8: 읽을 수 있는 행 길이와 적절한 정보 밀도로 시각적 부담을 줄인다.
- H6: 줄바꿈 뒤에도 라벨과 선택 요소의 관계를 바로 알아보게 한다.
- H4: 페이지 간 콘텐츠 폭·정렬·간격의 규칙을 유지한다.
- H7: 긴 목록은 필요한 검색·필터·그룹화로 탐색을 돕는다.
- 콘텐츠 중심 반응형 설계로 열 수와 배치 변경의 이유를 설명한다.

## 검토 질문

1. 360·390·768·1280px에서 각 영역의 열 수와 읽기 순서가 적절한가?
2. 긴 한국어 문장·이름이 여러 줄이 되어도 겹침·잘림이 없는가?
3. 체크박스와 첫 텍스트 줄이 가까이 정렬되고 전체 항목이 한 덩어리로 보이는가?
4. 고정 높이·최소 폭·그리드 규칙이 콘텐츠를 밀어내거나 빈 공간을 만들지 않는가?
5. 작은 화면에서 폼·도구 모음·저장 버튼이 자연스럽게 재배치되는가?
6. 확대·최대 목록·오류 문구·카드 인쇄에서도 내용을 읽고 조작할 수 있는가?

## 검토 방식과 산출물

가장 긴 가상 콘텐츠와 최대 항목 수를 먼저 준비한다. 폭별 열 수·콘텐츠 최대 폭·줄바꿈·간격의 설계안을 만들고, 폭 사이에서도 무너지는 구간이 없는지 확인한다. 가로 넘침 측정과 실제 스크린샷을 함께 검토한다.

- 폭별 페이지·섹션·목록 배치표
- 긴 텍스트·빈 목록·최대 항목 수에 대한 처리 규칙
- 타이포그래피와 정렬·간격의 수정 제안
- 재현 가능한 화면 조건과 개별 판정

## 통과를 막는 문제

내용 겹침·잘림, 의미를 잃는 줄바꿈, 라벨과 체크박스의 분리, 화면 밖 주요 버튼, 핵심 과업을 방해하는 페이지 전체 가로 이동은 수정이 필요하다. 글씨를 지나치게 줄이거나 문장을 숨겨서 통과시키지 않는다.

## 마니또 적용과 협업

4~40명 참가자와 긴 미션 선택지를 검토한다. 미션을 무조건 네 열에 맞추지 않고 문장 길이에 맞는 행·열·선택 카드 구조를 제안한다. WD-01의 시각 위계를 유지하고 UI-01의 조작 영역, UI-02의 확대·재배치 검증과 연결한다.

전체 휴리스틱, 심각도와 기록 형식은 [공통 검토 지침](README.md)을 따른다.
